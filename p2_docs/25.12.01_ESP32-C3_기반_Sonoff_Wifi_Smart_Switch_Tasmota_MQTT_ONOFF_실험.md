## ESP32-C3 기반 Sonoff Wifi Smart Switch + Tasmota + MQTT ON/OFF 실험

---

### 실험 제목: ESP32-C3(Sonoff Smart Switch 내부 보드) 기반 Tasmota 펌웨어 플래싱 및 MQTT 제어 가능성 검증 실험

### 실험 목적:

### 용어 정리

- **Sonoff WiFi Smart Switch**
    - **스마트폰 앱을 이용해 Wi-Fi 네트워크를 통해 가전제품의 전원을 원격으로 제어할 수 있는 장치**
    - 일반적인 전등 스위치나 가전제품에 연결하여, 스마트폰 앱(예: [**eWeLink 앱**](https://manuals.plus/ko/sonoff/switch-wf-wifi-smart-switch-manual))을 통해 원격으로 켜고 끄는 것은 물론, 타이머 설정이나 자동화 기능도 활용할 수 있게 만들어줌
    
    ![image.png](attachment:1819075c-4e26-4b7a-880d-51750a22ac57:image.png)
    
- **Tasmota**
    - ESP8266/ESP32 기기를 “내 마음대로 제어 가능한 스마트홈 기기”로 바꿔주는 오픈소스 펌웨어
        - 펌웨어 = 하드웨어 안에 들어가는 작은 운영체제/프로그램
    - Tasmota를 올리면:
        - 처음 부팅할 때 **자기만의 WiFi AP**를 띄움
            
            → `tasmota-XXXX` 같은 이름
            
        - 웹페이지(192.168.4.1)에서
            - 집 WiFi 정보 입력
            - MQTT 서버 정보 입력
        - 이후에는 **MQTT, HTTP 명령**으로 릴레이 on/off, 센서값 읽기 등을 할 수 있음
    - 특징
        - 코드를 따로 안 짜도 됨 (웹 UI + 설정만으로 동작)
        - Home Assistant, SmartThings 같은 플랫폼과 연동 쉬움
        - 완전 오픈소스
    - 이번 실험에서 쓴 파일: **`tasmota32c3.factory.bin`**
        
        → ESP32-C3용, 처음 플래싱할 때 쓰는 Tasmota 펌웨어
        
- **MQTT**
    - MQTT는 'Message Queuing Telemetry Transport'의 약자로, **사물 인터넷(IoT)과 같은 환경에서 사용되는 경량의 게시-구독(publish-subscribe) 메시지 프로토콜**
    - **게시-구독 모델:** 클라이언트들이 특정 `Topic`을 주제로 메시지를 게시(`Publish`)하고, 해당 `Topic`을 구독(`Subscribe`)하여 메시지를 받아가는 방식
        - **Topic(토픽)**:
            - 메시지 “방 이름” 같은 것
            - 예: `cmnd/sonoff01/Power`, `tele/sonoff01/STATE`
        - **Publish(발행)**:
            - “이 방에 메세지 보냄”
        - **Subscribe(구독)**:
            - “이 방에서 오는 메세지 계속 듣겠다”
        - **브로커(Broker):** 게시자와 구독자 사이에 `Broker`라는 중계 서버가 있어, 메시지를 대신 전달하는 역할
    
    ![image.png](attachment:fd350bd2-cd2b-4770-a5b5-a9520e32f50f:image.png)
    
    - 예시:
        - PC에서:
            - `cmnd/sonoff01/Power` 토픽에 `"ON"` 메시지 발행
        - Sonoff(Tasmota)가 그 토픽을 구독하고 있다가:
            - `"ON"` 받으면 릴레이 켬
            - `"OFF"` 받으면 릴레이 끔
- **Mosquitto**
    - PC에서 간단하게 띄울 수 있는 MQTT 브로커(서버) 프로그램
    - 설치 후 `mosquitto` 명령만 치면 MQTT 서버가 열림
    - 역할: Sonoff(Tasmota)와 테스트용 PC(또는 다른 기기) 사이에서 MQTT 메시지를 중개해 줌
        - 이번 실험에서는:
            - **브로커**: 내 PC (Mosquitto 실행 중)
            - **클라이언트 1**: Sonoff Tasmota (릴레이 on/off)
            - **클라이언트 2**: 테스트용 PC 터미널 (mosquitto_pub / mosquitto_sub)
            
            ```
                      (브로커)
                 ┌─────────────────┐
                 │   PC (Mosquitto) │
                 └─────────────────┘
                 ▲               ▲
                 │               │
                 │ MQTT 메시지    │ MQTT 메시지
                 │               │
            ┌─────────────────┐     ┌─────────────────────────┐
            │  PC 터미널       │     │  Sonoff Tasmota 기기     │
            │ (pub/sub 클라이언트)│ ←→ │ (릴레이 on/off 클라이언트) │
            └─────────────────┘     └─────────────────────────┘
            ```
            

### 전체 실험 시나리오

1. **Sonoff 내부 ESP32-C3에 Tasmota 펌웨어 플래싱**
- 펌웨어 플래싱
    - IoT 기기 안에는 플래시 메모리 라는 작은 저장공간이 있음
    - 플래싱 이란 이 저장공간을 지우고 새 프로그램을 넣는 과정
1. **완제품 Sonoff를 220V에 연결 → Tasmota AP 생성**
2. **AP 접속 → WiFi 정보 입력**
3. **PC에서 Mosquitto MQTT 서버 실행**
4. **Tasmota 웹 설정에서 MQTT 서버 주소(PC IP) 입력**
5. **PC에서 MQTT 메시지로 릴레이 ON/OFF 명령 전송**
6. **Sonoff 릴레이 동작 확인 (클릭 소리 + LED)**

### 실제 진행 과정

### **1. Sonoff 분해 + 내부 PCB 분리**

- Sonoff 완제품에서 **내부 PCB를 분리**
- 보드 뒷면에서 다음 패드 확인:
    - `3V3`, `RX`, `TX`, `GND` → UART 통신용
        - UART: 기기와 PC가 서로 문자(데이터)를 주고받는 가장 기본적인 통신 방식
        - TX: 내가 보내는 선 (transmit)
        - RX: 내가 받는 선 (Receive)
    - `KEY` (GPIO8) → BOOT 모드(Flash Mode) 진입용
        - 평소에는 ESP32가 ‘정상 모드’로 부팅
        - 새 프로그램을 넣기 위해서는 기기를 ‘업데이트 모드’로 넣어야 함 → BOOT 모드
        - KEY(GPIO8) 를 GND에 살짝 쇼트 시킨 채로 USB 연결 후 1초 뒤 쇼트 해제 하면 BOOT 모드로 들어가게 됨

![image.png](attachment:f58855e6-9de4-4144-83ee-5813724240c0:image.png)

- USB-TTL 모듈과 납땜 연결:
    - USB-TTL **3.3V ↔ 보드 3V3**
    - USB-TTL **GND ↔ 보드 GND**
    - USB-TTL **TX ↔ 보드 RX**
    - USB-TTL **RX ↔ 보드 TX**

### 4. Tasmota 펌웨어(Tasmota32C3.factory.bin) 플래싱

**(1) 펌웨어 다운로드 https://ota.tasmota.com/tasmota32/release/**

- Tasmota 공식 페이지에서 **`tasmota32c3.factory.bin`** 다운로드
    - ESP32-C3용 Tasmota 최초 설치용 펌웨어

**(2) 펌웨어 플래싱**

```jsx
cd C:\Users\user03\Downloads
```

```jsx
python -m esptool --chip esp32c3 --baud 115200 --port COM13 write-flash -z 0x0 "C:\Users\user03\Downloads\tasmota32c3.factory.bin"
```

### 6. Tasmota 초기 설정

- WiFi 목록에서 Tasmota AP (tasmota-C3-XXXXX) 뜨는지 확인
- 연결하면 자동 접속 → 설정 웹 페이지 열림
    - 자동으로 안 뜨면 → 브라우저에서 http://192.168.4.1 입력
- WiFi SSID 와 비밀번호 입력
    - 저장하면 Tasmota가 WiFi에 연결됨

### 7. Tasmota → MQTT 브로커 연결

**(1) Mosquitto 브로커 실행**

```jsx
mosquitto -v
```

이렇게 하면:

- **로컬 MQTT 서버 실행됨**
- 디폴트 IP: `192.168.0.xxx` (PC LAN IP)

**(2) Tasmota에서 MQTT 설정**

- 웹 브라우저로 Tasmota의 IP 접속:
    - 예:  `http://192.168.0.21`
- 메뉴:

```
Configuration → Configure MQTT
```

- 필수 항목:

```
Host: (PC IP 주소)
User: (없으면 비워둠)
Password: (없으면 비워둠)
Topic: sonoff01 (원하는 이름)
```

→ 저장하면 자동으로 MQTT 서버와 연결됨

### 8. MQTT로 릴레이 On/Off 명령 내려보기

PC 터미널에서: 

```jsx
# ON
mosquitto_pub -h 192.168.0.10 -t cmnd/sonoff01/Power -m "ON"

# OFF
mosquitto_pub -h 192.168.0.10 -t cmnd/sonoff01/Power -m "OFF"

# 상태 확인
mosquitto_sub -h 192.168.0.10 -t stat/esp32c3/#
```

→ 릴레이 딸깍 소리나고 실행됨, LED도 상태에 따라 바뀜
