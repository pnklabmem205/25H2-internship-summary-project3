## v0.2 (얼굴 검출 박스 + /snapshot) 구현

https://github.com/pnkmem432/esp-who-face_entry/tree/v0.2/examples/human_face_recognition/main

### **v0.2 목표**

- 웹 브라우저에서 `/stream` 으로 **실시간 영상 스트리밍**
- 스트림 위에 **얼굴 검출 박스(초록 박스) + confidence(%) 오버레이**
- **로그에서 얼굴 유무를 쉽게 확인**할 수 있게 (`faces = 0 / N`) 출력
- 기본 `/snapshot` 엔드포인트는 유지단일 캡처용)

### 주요 구성 요소

- **보드/환경**
    - ESP32-S3 (ESP-S3-EYE 계열, OV2640 카메라)
    - ESP-IDF v5.4.2 + esp-who `human_face_recognition` 예제 기반 커스터마이징
    - 카메라 래퍼: `who::cam::WhoS3Cam`

### 1) 네트워크 / Wi-Fi

- 파일: `app_main.cpp`
- 기능:
    - `wifi_init()` 에서 **STA 모드 + 정적 IP 설정**
        - 예시: IP `192.168.0.15`, Mask `255.255.255.0`, GW `192.168.0.1`
    - 이벤트 핸들러에서 IP 획득 시 로그:
        - `Got IP: 192.168.0.15`
        - `Wi-Fi connected, STATIC IP = 192.168.0.15`

### 2) 카메라 초기화

- 파일: `app_main.cpp`
- 코드 개념:
    
    ```cpp
    auto *cam = new who::cam::WhoS3Cam(
        PIXFORMAT_JPEG,
        FRAMESIZE_QVGA,   // v0.2 최종: 검출 속도/성능 균형점
        5,                // FPS 타깃

        true              // PSRAM 사용
    );
    ```
    
- 특징:
    - **프레임은 JPEG로 캡처**, 이후 RGB888로 변환해서 얼굴 검출 수행
    - QVGA 기준으로 딥러닝 inference 속도 확보

### 3) HTTP 서버

- 파일: `http_server_ex.cpp`, `http_server_ex.hpp`
- 엔드포인트:
    1. `/`
        - 간단한 HTML 페이지
        - `<img src="/stream" style="width:100%">`
        - 브라우저에서 바로 스트림 확인용
    2. `/stream`
        - **`multipart/x-mixed-replace` 형식의 MJPEG 스트림**
        - 루프:
            1. `cam->cam_fb_get()` 으로 프레임 획득
            2. `who_fp::g_face_processor.process_and_draw(fb, &jpeg_buf, &jpeg_len)` 호출
                
                → 얼굴 검출 + 박스/텍스트 오버레이 + JPEG 인코딩
                
            3. HTTP chunk로 전송
            4. 버퍼 해제 후 반복
    3. `/snapshot`
        - 단일 이미지 캡처 엔드포인트
        - 현재 구현:
            - 카메라 프레임 1장 획득 후 **그대로 JPEG 전송**
            - **얼굴 검출/박스 없음 (원본 프레임 그대로)**

### 얼굴 검출 / 오버레이 로직

- 파일: `face_processor.hpp`, `face_processor.cpp`
- 네임스페이스: `who_fp`

### 1) 전역 객체

- `static HumanFaceDetect s_detector;`
    - esp-dl 의 얼굴 검출 모델 래퍼
- `FaceProcessor g_face_processor;`
    - `/stream` 에서 사용하는 처리기

### 2) RGB 변환 + 얼굴 검출

`FaceProcessor::process_and_draw(const cam_fb_t &fb, uint8_t **jpeg_buf, size_t *jpeg_len)` 흐름:

1. **입력 프레임 검증**
    - `fb.width`, `fb.height`, `fb.len` 확인
    - 내부 RGB 버퍼 크기(`rgb_buf_`)가 부족하면 PSRAM에 재할당
2. **JPEG → RGB888 변환**
    
    ```cpp
    fmt2rgb888(
        static_cast<const uint8_t *>(fb.buf),
        fb.len,
        static_cast<pixformat_t>(fb.format),
        rgb_buf_);
    ```
    
3. **딥러닝 얼굴 검출**
    
    ```cpp
    dl::image::img_t img{};
    img.data     = rgb_buf_;
    img.width    = width;
    img.height   = height;
    img.pix_type = dl::image::DL_IMAGE_PIX_TYPE_RGB888;
    
    auto det_list = s_detector.run(img);
    ESP_LOGI(TAG_FP, "stream overlay: faces=%d", (int)det_list.size());
    ```
    
    - `faces=0` → 얼굴 없음
    - `faces>0` → 검출된 얼굴 수

### 3) 초록 박스 + confidence 텍스트

- 검출 결과 `det_list` 순회하며:
    
    ```cpp
    // r.box: std::vector<int> [x1, y1, x2, y2]
    int x1 = r.box[0];
    int y1 = r.box[1];
    int x2 = r.box[2];
    int y2 = r.box[3];
    
    // 경계 체크 및 화면 범위 클램프 후
    draw_rect_rgb(rgb_buf_, width, height, x1, y1, bw, bh, 2,
                  0, 255, 0); // 초록 박스
    ```
    
- confidence(0.0~1.0) → 정수 % 변환 후 `"93%"` 문자열 생성
- 미니 5x7 폰트로 초록색 텍스트 렌더링:
    
    ```cpp
    draw_text_rgb(rgb_buf_, width, height,
                  x1, text_y,
                  label,
                  0, 255, 0);
    ```
    

### 4) RGB → JPEG 재인코딩

- 최종적으로 오버레이가 적용된 RGB를 JPEG로 변환:
    
    ```cpp
    fmt2jpg(
        rgb_buf_,
        need,                   // src_len (width*height*3)
        width,
        height,
        PIXFORMAT_RGB888,
        80,                     // 품질 0~100
        jpeg_buf,
        jpeg_len);
    ```
    
- `/stream` 은 이 JPEG를 브라우저로 chunk 전송

    // 간이 임베더: 얼굴 영역을 16x16 그리드로 다운샘플 → 회색조 평균 0~1 float
    class FaceEmbedderLite
    {
    public:
        bool extract(uint8_t *rgb,
                     int width,
                     int height,
                     const dl::detect::result_t &box,
                     std::vector<float> &out_feat)
        {
            if (!rgb) return false;
            if (box.box.size() < 4) return false;
    
            int x1 = box.box[0];
            int y1 = box.box[1];
            int x2 = box.box[2];
            int y2 = box.box[3];
    
            if (x1 < 0) x1 = 0;
            if (y1 < 0) y1 = 0;
            if (x2 >= width)  x2 = width - 1;
            if (y2 >= height) y2 = height - 1;
            if (x2 <= x1 || y2 <= y1) return false;
    
            const int bw = x2 - x1 + 1;
            const int bh = y2 - y1 + 1;
    
            const int GRID = 16;   // 16x16 = 256차원
            out_feat.assign(GRID * GRID, 0.0f);
    
            for (int gy = 0; gy < GRID; ++gy)
            {
                for (int gx = 0; gx < GRID; ++gx)
                {
                    // cell 중앙 위치
                    float fx = x1 + (gx + 0.5f) * bw / GRID;
                    float fy = y1 + (gy + 0.5f) * bh / GRID;
                    int sx = static_cast<int>(fx);
                    int sy = static_cast<int>(fy);
    
                    if (sx < 0) sx = 0;
                    if (sy < 0) sy = 0;
                    if (sx >= width)  sx = width  - 1;
                    if (sy >= height) sy = height - 1;
    
                    size_t idx = (static_cast<size_t>(sy) * width + sx) * 3;
                    uint8_t r = rgb[idx + 0];
                    uint8_t g = rgb[idx + 1];
                    uint8_t b = rgb[idx + 2];
    
                    // 간단한 회색조 변환
                    float gray = 0.299f * r + 0.587f * g + 0.114f * b;
                    gray /= 255.0f;
    
                    out_feat[gy * GRID + gx] = gray;
                }
            }
    
            // L2 normalize
            float norm = 0.0f;
            for (float v : out_feat) norm += v * v;
            norm = std::sqrt(norm);
            if (norm > 1e-6f)
            {
                for (float &v : out_feat) v /= norm;
            }
    
            return true;
        }
    };
    
    static FaceEmbedderLite s_embedder;
    
    static float cosine_similarity(const std::vector<float> &a,
                                   const std::vector<float> &b)
    {
        if (a.size() != b.size() || a.empty()) return 0.0f;
    
        float dot = 0.0f;
        float na  = 0.0f;
        float nb  = 0.0f;
    
        for (size_t i = 0; i < a.size(); ++i)
        {
            dot += a[i] * b[i];
            na  += a[i] * a[i];
            nb  += b[i] * b[i];
        }
    
        if (na <= 1e-6f || nb <= 1e-6f) return 0.0f;
        return dot / (std::sqrt(na) * std::sqrt(nb));
    }
    
    // RGB + 박스 → DB와 비교해 가장 유사한 사람 찾기
    static bool recognize_face(uint8_t *rgb,
                               int width,
                               int height,
                               const dl::detect::result_t &box,
                               std::string &out_label,
                               float &out_sim)
    {
        out_label = "Unknown";
        out_sim   = 0.0f;
    
        if (s_face_db.empty()) {
            return false;   // 등록된 사람이 없음
        }
    
        std::vector<float> feat;
        if (!s_embedder.extract(rgb, width, height, box, feat)) {
            return false;
        }
    
        float best_sim = 0.0f;
        int   best_idx = -1;
    
        for (size_t i = 0; i < s_face_db.size(); ++i)
        {
            float sim = cosine_similarity(feat, s_face_db[i].embedding);
            if (sim > best_sim)
            {
                best_sim = sim;
                best_idx = static_cast<int>(i);
            }
        }
    
        if (best_idx < 0) return false;
    
        // threshold: 0.8 이상일 때만 "그 사람"으로 간주
        const float THRESH = 0.80f;
        if (best_sim >= THRESH)
        {
            out_label = s_face_db[best_idx].name;
            out_sim   = best_sim;
            return true;
        }
    
        // threshold 미만이면 Unknown
        out_label = "Unknown";
        out_sim   = best_sim;
        return true;
    }

    static inline void put_pixel_rgb(uint8_t *rgb,
                                     int width,
                                     int height,
                                     int x,
                                     int y,
                                     uint8_t r,
                                     uint8_t g,
                                     uint8_t b)
    {
        if (!rgb) return;
        if (x < 0 || y < 0 || x >= width || y >= height) return;
    
        size_t idx = (static_cast<size_t>(y) * width + x) * 3;
        rgb[idx + 0] = r;
        rgb[idx + 1] = g;
        rgb[idx + 2] = b;
    }
    
    static void draw_rect_rgb(uint8_t *rgb,
                              int width,
                              int height,
                              int x,
                              int y,
                              int w,
                              int h,
                              int thickness,
                              uint8_t r,
                              uint8_t g,
                              uint8_t b)
    {
        if (!rgb) return;
        if (w <= 0 || h <= 0) return;
    
        for (int t = 0; t < thickness; ++t)
        {
            int yt = y + t;
            int yb = y + h - 1 - t;
            for (int xi = x; xi < x + w; ++xi)
            {
                put_pixel_rgb(rgb, width, height, xi, yt, r, g, b);
                put_pixel_rgb(rgb, width, height, xi, yb, r, g, b);
            }
    
            int xl = x + t;
            int xr = x + w - 1 - t;
            for (int yi = y; yi < y + h; ++yi)
            {
                put_pixel_rgb(rgb, width, height, xl, yi, r, g, b);
                put_pixel_rgb(rgb, width, height, xr, yi, r, g, b);
            }
        }
    }

    static const uint8_t FONT_5x7[][7] = {
        // '0'
        {0b01110, 0b10001, 0b10011, 0b10101, 0b11001, 0b10001, 0b01110},
        // '1'
        {0b00100, 0b01100, 0b00100, 0b00100, 0b00100, 0b00100, 0b01110},
        // '2'
        {0b01110, 0b10001, 0b00001, 0b00010, 0b00100, 0b01000, 0b11111},
        // '3'
        {0b11110, 0b00001, 0b00001, 0b01110, 0b00001, 0b00001, 0b11110},
        // '4'
        {0b00010, 0b00110, 0b01010, 0b10010, 0b11111, 0b00010, 0b00010},
        // '5'
        {0b11111, 0b10000, 0b11110, 0b00001, 0b00001, 0b10001, 0b01110},
        // '6'
        {0b00110, 0b01000, 0b10000, 0b11110, 0b10001, 0b10001, 0b01110},
        // '7'
        {0b11111, 0b00001, 0b00010, 0b00100, 0b01000, 0b01000, 0b01000},
        // '8'
        {0b01110, 0b10001, 0b10001, 0b01110, 0b10001, 0b10001, 0b01110},
        // '9'
        {0b01110, 0b10001, 0b10001, 0b01111, 0b00001, 0b00010, 0b01100},
        // '%'
        {0b11000, 0b11001, 0b00010, 0b00100, 0b01000, 0b10011, 0b00011},
    };
    
    static int font_index_for_char(char c)
    {
        if (c >= '0' && c <= '9')
            return c - '0';
        if (c == '%')
            return 10;
        return -1;
    }
    
    static void draw_char_rgb(uint8_t *rgb,
                              int width,
                              int height,
                              int x,
                              int y,
                              char c,
                              uint8_t r,
                              uint8_t g,
                              uint8_t b)
    {
        int idx = font_index_for_char(c);
        if (idx < 0) return;
    
        for (int row = 0; row < 7; ++row)
        {
            uint8_t bits = FONT_5x7[idx][row];
            for (int col = 0; col < 5; ++col)
            {
                if (bits & (1 << (4 - col)))
                {
                    put_pixel_rgb(rgb, width, height,
                                  x + col,
                                  y + row,
                                  r, g, b);
                }
            }
        }
    }
    
    static void draw_text_rgb(uint8_t *rgb,
                              int width,
                              int height,
                              int x,
                              int y,
                              const char *text,
                              uint8_t r,
                              uint8_t g,
                              uint8_t b)
    {
        if (!text) return;
        int cursor_x = x;
        while (*text)
        {
            draw_char_rgb(rgb, width, height, cursor_x, y, *text, r, g, b);
            cursor_x += 6; // 5픽셀 + 1픽셀 간격
            ++text;
        }
    }

    bool FaceProcessor::process_and_draw(const cam_fb_t &fb,

                                         size_t *jpeg_len)
    {
        if (!jpeg_buf || !jpeg_len)
        {
            return false;
        }
    
        *jpeg_buf = nullptr;
        *jpeg_len = 0;
    
        const int width  = fb.width;
        const int height = fb.height;
        const size_t need = static_cast<size_t>(width) * height * 3; // RGB888
    
        // RGB 버퍼 확보
        if (!rgb_buf_ || rgb_buf_size_ < need)
        {
            if (rgb_buf_)
            {
                heap_caps_free(rgb_buf_);
            }
            rgb_buf_ = static_cast<uint8_t *>(
                heap_caps_malloc(need, MALLOC_CAP_8BIT | MALLOC_CAP_SPIRAM));
            if (!rgb_buf_)
            {
                ESP_LOGE(TAG_FP, "No memory for RGB buffer (stream)");
                return false;
            }
            rgb_buf_size_ = need;
        }
    
        // JPEG(or RGB565) → RGB888 변환
        if (!fmt2rgb888(
                static_cast<const uint8_t *>(fb.buf),
                fb.len,
                static_cast<pixformat_t>(fb.format),
                rgb_buf_))
        {
            ESP_LOGW(TAG_FP, "fmt2rgb888 failed (stream)");
            return false;
        }
    
        // 얼굴 검출
        dl::image::img_t img{};
        img.data     = rgb_buf_;
        img.width    = static_cast<uint16_t>(width);
        img.height   = static_cast<uint16_t>(height);
        img.pix_type = dl::image::DL_IMAGE_PIX_TYPE_RGB888;
    
        auto det_list = s_detector.run(img);
        ESP_LOGI(TAG_FP, "stream overlay: faces=%d", (int)det_list.size());
    
        // ──────────────────────────────────
        //  히스테리시스: 박스 흔들림 완화
        // ──────────────────────────────────
        std::vector<dl::detect::result_t> draw_list;
    
        if (!det_list.empty())
        {
            s_last_boxes.assign(det_list.begin(), det_list.end());
            s_miss_count = 0;
            draw_list    = s_last_boxes;
        }
        else
        {
            if (!s_last_boxes.empty() && s_miss_count < MISS_THRESHOLD)
            {
                s_miss_count++;
                draw_list = s_last_boxes;
            }
            else
            {
                s_last_boxes.clear();
                draw_list.clear();
            }
        }
    
        // 박스 + (Detection / Recognition) 텍스트 그리기
        for (auto &r : draw_list)
        {
            if (r.box.size() < 4)
            {
                continue;
            }
    
            int x1 = r.box[0];
            int y1 = r.box[1];
            int x2 = r.box[2];
            int y2 = r.box[3];
    
            int bw = x2 - x1 + 1;
            int bh = y2 - y1 + 1;
    
            // 화면 범위 클램프
            x1 = std::max(0, x1);
            y1 = std::max(0, y1);
            if (x1 >= width || y1 >= height) continue;
            bw = std::min(bw, width  - x1);
            bh = std::min(bh, height - y1);
            if (bw <= 0 || bh <= 0) continue;
    
            // 초록 박스 (두께 2)
            draw_rect_rgb(rgb_buf_, width, height,
                          x1, y1, bw, bh, 2,
                          0, 255, 0);
    
            // 텍스트 내용 결정
            char label_text[32] = {0};
    
            if (s_face_db.empty())
            {
                // 아직 등록된 얼굴이 없으면: Detection confidence만 표시 (기존 v0.2 스타일)
                int conf = static_cast<int>(r.score * 100.0f + 0.5f);
                if (conf < 0)  conf = 0;
                if (conf > 99) conf = 99;
                std::snprintf(label_text, sizeof(label_text), "%d%%", conf);
            }
            else
            {
                // 등록된 얼굴이 있으면 Recognition 수행
                std::string name;
                float       sim = 0.0f;
                bool ok = recognize_face(rgb_buf_, width, height, r, name, sim);
    
                if (!ok)
                {
                    int conf = static_cast<int>(r.score * 100.0f + 0.5f);
                    if (conf < 0)  conf = 0;
                    if (conf > 99) conf = 99;
                    std::snprintf(label_text, sizeof(label_text), "%d%%", conf);
                }
                else
                {
                    if (name == "Unknown")
                    {
                        std::snprintf(label_text, sizeof(label_text), "Unknown");
                    }
                    else
                    {
                        int pct = static_cast<int>(sim * 100.0f + 0.5f);
                        if (pct < 0)   pct = 0;
                        if (pct > 100) pct = 100;
                        std::snprintf(label_text, sizeof(label_text),
                                      "%s %d%%", name.c_str(), pct);
                    }
                }
            }
    
            int text_y = y1 - 10;
            if (text_y < 0)
                text_y = y1 + 2;
    
            draw_text_rgb(rgb_buf_, width, height,
                          x1, text_y,
                          label_text,
                          0, 255, 0);
        }
    
        // RGB → JPEG 인코딩
        if (!fmt2jpg(rgb_buf_,
                     need,                               // src_len (byte)
                     static_cast<uint16_t>(width),
                     static_cast<uint16_t>(height),
                     PIXFORMAT_RGB888,
                     80,                                // 품질 0~100
                     jpeg_buf,
                     jpeg_len))
        {
            ESP_LOGE(TAG_FP, "fmt2jpg failed");
            return false;
        }
    
        return true;
    }
    
    bool FaceProcessor::register_face_from_frame(const cam_fb_t &fb,
                                                 const char *name)
    {
        if (!name || !name[0]) {
            ESP_LOGW(TAG_FP, "register_face_from_frame: empty name");
            return false;
        }
    
        const int width  = fb.width;
        const int height = fb.height;
        const size_t need = static_cast<size_t>(width) * height * 3; // RGB888
    
        // RGB 버퍼 확보
        if (!rgb_buf_ || rgb_buf_size_ < need)
        {
            if (rgb_buf_)
            {
                heap_caps_free(rgb_buf_);
            }
            rgb_buf_ = static_cast<uint8_t *>(
                heap_caps_malloc(need, MALLOC_CAP_8BIT | MALLOC_CAP_SPIRAM));
            if (!rgb_buf_)
            {
                ESP_LOGE(TAG_FP, "No memory for RGB buffer (register)");
                return false;
            }
            rgb_buf_size_ = need;
        }
    
        // JPEG(or RGB565) → RGB888 변환
        if (!fmt2rgb888(
                static_cast<const uint8_t *>(fb.buf),
                fb.len,
                static_cast<pixformat_t>(fb.format),
                rgb_buf_))
        {
            ESP_LOGW(TAG_FP, "fmt2rgb888 failed (register)");
            return false;
        }
    
        // 얼굴 검출 (가장 첫 번째 얼굴만 사용)
        dl::image::img_t img{};
        img.data     = rgb_buf_;
        img.width    = static_cast<uint16_t>(width);
        img.height   = static_cast<uint16_t>(height);
        img.pix_type = dl::image::DL_IMAGE_PIX_TYPE_RGB888;
    
        auto det_list = s_detector.run(img);
        if (det_list.empty())
        {
            ESP_LOGW(TAG_FP, "register_face: no face found");
            return false;
        }
    
        auto &first = det_list.front();
    
        std::vector<float> feat;
        if (!s_embedder.extract(rgb_buf_, width, height, first, feat))
        {
            ESP_LOGW(TAG_FP, "register_face: embedding failed");
            return false;
        }
    
        // 같은 이름이 이미 있으면 덮어쓰기
        bool replaced = false;
        for (auto &f : s_face_db)
        {
            if (f.name == name)
            {
                f.embedding = feat;
                replaced = true;
                break;
            }
        }
        if (!replaced)
        {
            RegisteredFace rf;
            rf.name      = name;
            rf.embedding = std::move(feat);
            s_face_db.push_back(std::move(rf));
        }
    
        ESP_LOGI(TAG_FP, "register_face: name=%s, db_size=%d",
                 name, (int)s_face_db.size());
        return true;
    }

    static esp_err_t index_handler(httpd_req_t *req)
    {
    const char *page =
    "<html><body style='margin:0;background:#000'>"
    "<div style='display:flex;flex-direction:column;align-items:center;'>"

    // /stream : 얼굴 박스 + confidence/이름 포함 스트림
    static esp_err_t stream_handler(httpd_req_t *req)
    {
    httpd_resp_set_type(
    req,
    "multipart/x-mixed-replace; boundary=frame");
    
    char hdr[64];
    
    while (true)
    {
        cam_fb_t *fb = s_cam->cam_fb_get();
        if (!fb) {
            vTaskDelay(pdMS_TO_TICKS(30));
            continue;
        }
    
        uint8_t *jpeg_buf = nullptr;
        size_t   jpeg_len = 0;
    
        bool ok = g_face_processor.process_and_draw(*fb, &jpeg_buf, &jpeg_len);
    
        s_cam->cam_fb_return(fb);
    
        if (!ok || !jpeg_buf || jpeg_len == 0) {
            if (jpeg_buf) {
                free(jpeg_buf);
            }
            ESP_LOGW(TAG, "process_and_draw failed, skip frame");
            vTaskDelay(pdMS_TO_TICKS(30));
            continue;
        }
    
        int hlen = snprintf(
            hdr, sizeof(hdr),
            "--frame\\r\\n"
            "Content-Type: image/jpeg\\r\\n"
            "Content-Length: %u\\r\\n\\r\\n",
            (unsigned)jpeg_len);
    
        if (httpd_resp_send_chunk(req, hdr, hlen) != ESP_OK) {
            free(jpeg_buf);
            break;
        }
    
        if (httpd_resp_send_chunk(
                req,
                reinterpret_cast<const char *>(jpeg_buf),
                jpeg_len) != ESP_OK)
        {
            free(jpeg_buf);
            break;
        }
    
        if (httpd_resp_send_chunk(req, "\\r\\n", 2) != ESP_OK) {
            free(jpeg_buf);
            break;
        }
    
        free(jpeg_buf);
        vTaskDelay(pdMS_TO_TICKS(30));
    }
    
    return ESP_OK;
    
    }
    
    // /snapshot : 현재 프레임 한 장 JPEG
    static esp_err_t snapshot_handler(httpd_req_t *req)
    {
    cam_fb_t *fb = s_cam->cam_fb_get();
    if (!fb) {
    return ESP_FAIL;
    }
    
    uint8_t *jpeg_buf = nullptr;
    size_t   jpeg_len = 0;
    
    bool ok = fmt2jpg(
        static_cast<uint8_t *>(fb->buf),   // src
        fb->len,                           // src_len
        static_cast<uint16_t>(fb->width),  // width
        static_cast<uint16_t>(fb->height), // height
        static_cast<pixformat_t>(fb->format), // PIXFORMAT_RGB565
        80,                                // quality
        &jpeg_buf,                         // out
        &jpeg_len);                        // out_len
    
    s_cam->cam_fb_return(fb);
    
    if (!ok || !jpeg_buf || jpeg_len == 0) {
        if (jpeg_buf) {
            free(jpeg_buf);
        }
        ESP_LOGE(TAG, "fmt2jpg failed in snapshot");
        return ESP_FAIL;
    }
    
    httpd_resp_set_type(req, "image/jpeg");
    esp_err_t res = httpd_resp_send(
        req,
        reinterpret_cast<const char *>(jpeg_buf),
        jpeg_len);
    
    free(jpeg_buf);
    return res;
    
    }
    
    // /register?name=person1 : 현재 프레임의 첫 얼굴을 name으로 등록
    static esp_err_t register_handler(httpd_req_t *req)
    {
    // 쿼리 문자열 길이 확인
    int qlen = httpd_req_get_url_query_len(req);
    if (qlen <= 0) {
    httpd_resp_set_status(req, "400 Bad Request");
    httpd_resp_send(req, "missing query", HTTPD_RESP_USE_STRLEN);
    return ESP_OK;
    }
    
    std::string query;
    query.resize(qlen + 1);
    if (httpd_req_get_url_query_str(req, query.data(), query.size()) != ESP_OK) {
        httpd_resp_set_status(req, "400 Bad Request");
        httpd_resp_send(req, "query parse error", HTTPD_RESP_USE_STRLEN);
        return ESP_OK;
    }
    
    char name[32] = {0};
    if (httpd_query_key_value(query.c_str(), "name", name, sizeof(name)) != ESP_OK ||
        name[0] == '\\0') {
        httpd_resp_set_status(req, "400 Bad Request");
        httpd_resp_send(req, "missing name", HTTPD_RESP_USE_STRLEN);
        return ESP_OK;
    }
    
    cam_fb_t *fb = s_cam->cam_fb_get();
    if (!fb) {
        httpd_resp_set_status(req, "500 Internal Server Error");
        httpd_resp_send(req, "no frame", HTTPD_RESP_USE_STRLEN);
        return ESP_OK;
    }
    
    bool ok = g_face_processor.register_face_from_frame(*fb, name);
    
    s_cam->cam_fb_return(fb);
    
    if (!ok) {
        httpd_resp_set_status(req, "500 Internal Server Error");
        httpd_resp_send(req, "register failed (no face?)", HTTPD_RESP_USE_STRLEN);
        return ESP_OK;
    }
    
    char msg[64];
    snprintf(msg, sizeof(msg), "registered: %s\\n", name);
    httpd_resp_set_type(req, "text/plain");
    httpd_resp_send(req, msg, HTTPD_RESP_USE_STRLEN);
    return ESP_OK;
    
    }
    
    static httpd_handle_t start_server()
    {
    httpd_config_t config = HTTPD_DEFAULT_CONFIG();
    config.server_port = 80;
    
    httpd_handle_t server = nullptr;
    if (httpd_start(&server, &config) == ESP_OK)
    {
        httpd_uri_t index_uri {
            .uri = "/",
            .method = HTTP_GET,
            .handler = index_handler,
            .user_ctx = nullptr
        };
        httpd_register_uri_handler(server, &index_uri);
    
        httpd_uri_t stream_uri {
            .uri = "/stream",
            .method = HTTP_GET,
            .handler = stream_handler,
            .user_ctx = nullptr
        };
        httpd_register_uri_handler(server, &stream_uri);
    
        httpd_uri_t snap_uri {
            .uri = "/snapshot",
            .method = HTTP_GET,
            .handler = snapshot_handler,
            .user_ctx = nullptr
        };
        httpd_register_uri_handler(server, &snap_uri);
    
        httpd_uri_t reg_uri {
            .uri = "/register",
            .method = HTTP_GET,
            .handler = register_handler,
            .user_ctx = nullptr
        };
        httpd_register_uri_handler(server, &reg_uri);
    
        ESP_LOGI(TAG, "HTTP server started");
    }
    
    return server;
    
    }
    
    } // extern "C"

- 얼굴 검출 초록 박스 위에 등록한 ID 와 % 출력
    - **등록된 사람이 하나도 없을 때** →
        
        `%` = **얼굴 검출 confidence(신뢰도)**
        
    - **등록된 사람이 있을 때, 매칭에 성공했을 때** →
        
        `%` = **저장된 임베딩과의 유사도(similarity)를 0~100으로 바꾼 값**
        
- 현재는 RAM 기반 DB → 전원 꺼지면 리셋
- SD 카드 혹은 SPI Flash에 임베딩 저장하는 구조로 확장 가능
- 간이 임베딩 → 추후 ESP-WHO의 얼굴 특징량 사용으로 교체 가능
