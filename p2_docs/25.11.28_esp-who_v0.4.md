## 2. 주요 파일 & 역할

### 2-1) `main/app_main.cpp`

- 역할:
    - NVS 초기화
    - Wi-Fi STA 연결 (`wifi_init_sta()`)
    - 카메라 초기화 (`WhoS3Cam`)
    - HTTP 서버 시작 (`start_http_server_ex(cam)`)
- 체크 포인트:
    - **카메라 설정**
        - `PIXFORMAT_JPEG`, `FRAMESIZE_QVGA`, FPS 등
    - **Wi-Fi SSID / PASSWORD**
        - 실제 사용하는 AP로 바꿔줘야 함

### 2-2) `main/face_processor.cpp`

- **얼굴 인식 엔진 + UI 오버레이**

### (1) 전역 객체/구조

- `static HumanFaceDetect s_detector;`
    
    → esp-who 얼굴 검출 모델
    
- `static HumanFaceFeat s_feat_model;`
    
    → 얼굴 임베딩(512차원 feature) 모델
    
- `struct RegisteredFace { std::string name; std::vector<float> embedding;};
static std::vector<RegisteredFace> s_face_db;`
    
    → 등록된 사용자 목록 (이게 DB 역할이지만, **플래시 저장 X, RAM에만 존재**)
    

### (2) 유사도 계산

```cpp
static float cosine_similarity(const std::vector<float> &a,
                               const std::vector<float> &b)
```

- 512차원 벡터 `a`, `b`를 넣어서 **코사인 유사도**를 리턴
- 결과 값은 0.0 ~ 1.0 , 여기서는 비슷하면 0.7 이상으로 나오도록 사용

### (3) 얼굴 인식 (`recognize_face()`)

- 흐름:
    1. RGB 프레임 + 얼굴 박스(box.keypoint)를 이용해
    2. `s_feat_model.run(img, box.keypoint)` → 512차원 feature 추출
    3. `s_face_db`의 모든 등록 사용자와 코사인 유사도 계산
    4. 가장 높은 유사도 > `THRESH(0.70f)`이면 → 그 이름 반환
        
        아니면 `"Unknown"`
        
- **중요 포인트**:
    - 이 버전에서는 **임베딩을 파일로 저장하지 않고, s_face_db 벡터에만 넣기 때문에 리셋 시 사라짐**

### (4) 스트림 처리 (`process_and_draw()`)

- 역할:
    1. 카메라 프레임(YUV/JPEG)을 RGB888로 변환 (`fmt2rgb888`)
    2. `s_detector.run(img)`로 얼굴 검출
    3. 박스를 `draw_rect_rgb()`로 그림
    4. `recognize_face()` 호출해서:
        - 등록된 사람이 없으면 → `score%`만 표시
        - 등록된 사람이 있으면 → `이름 + 유사도%` 표시
    5. 최종 RGB를 다시 `fmt2jpg()`로 JPEG로 바꿔 `/stream`에 전송

### (5) 등록 처리 (`register_face_from_frame()`)

- 동작 순서:
    1. 현재 카메라 프레임을 RGB888로 변환
    2. 얼굴 검출 후 첫 번째 얼굴 선택
    3. `s_feat_model.run()`으로 임베딩 추출
    4. `RegisteredFace{name, embedding}`을 `s_face_db`에 push
        - 이미 같은 이름이 있으면 덮어쓰기
- **v0.3.1의 핵심 한계**:
    - 여기까지는 “등록 → 스트림에서 인식”이 잘 되지만,
    - **전원을 끄거나 리셋하면 `s_face_db`는 날아감**
    - 즉, 한 세션 동안만 임시 DB
