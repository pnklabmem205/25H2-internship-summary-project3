            ### (1) 파티션 테이블에서 얼굴용 영역을 따로 둔다
            
            대략 이런 파티션 예시:
            
            ```
            # Name,   Type, SubType, Offset,  Size,   Flags
            nvs,      data, nvs,     0x9000,  0x5000,
            phy_init, data, phy,     0xe000,  0x1000,
            factory,  app,  factory, 0x10000, 1M,
            ota_0,    app,  ota_0,          1M,
            storage,  data, spiffs,         2M,
            ```
            
            - `factory`, `ota_0` → 펌웨어(코드) 올라가는 부분
            - `storage` → `/spiflash` 마운트해서 `faces.bin` 같은 데이터 저장
            
            **중요한 건:**
            
            이렇게 해 놓고도, 매번 `flash`로 **storage 파티션까지 새로 굽고 있으면 아무 의미 없음**
            
            ---
            
            ### (2) 개발할 때는 “앱만 플래시” 한다
            
            처음 한 번:
            
            ```bash
            idf.py -p COMx flash# 부트로더/파티션/앱/스토리지 한 번만 굽기
            ```
            
            그 이후 펌웨어 수정 시:
            
            ```bash
            idf.py -p COMx app-flash# 앱 파티션만 업데이트
            ```
            
            이렇게 하면:
            
            - `factory` / `ota_0`에 올라간 **펌웨어만 교체**
            - `storage` 파티션에 있는 `faces.bin`은 그대로 유지 → **등록 얼굴 안 날아감**
            
            만약 프로젝트에서 SPIFFS/LittleFS 이미지를 매번 만들어서 자동 플래시하고 있다면:
            
            - `menuconfig`에서 “SPIFFS 이미지 플래시” 옵션 꺼두거나
            - 스토리지 이미지는 진짜 필요할 때만(초기 세팅 바꿀 때만) 다시 굽기
