## 고정 카메라 기준 Head Pose 방향 판별 실험

https://github.com/pnkmem432/HEADPOSE/blob/main/headpose_webcam_direction.py

https://drive.google.com/drive/folders/1L3loXAyneqYd6lTu29LwBWNfbnjpxY3b?hl=ko — `고정 카메라 기준 Head Pose 방향 판별 실험.mp4` 참

### 1. 목표

본 시스템은 개인별 시선(gaze)을 추정하는 것이 아니라, 고정된 카메라 좌표계를 기준으로 통행자의 머리 방향(head pose)을 추정하는 것을 목표로 한다.

### 2. 실험 내용

- **기준은 카메라 렌즈가 정면으로 보는 방향 → 자기 자신을 원점(0,0,0)으로 놓고 판단함**
    
    얼굴을 하나의 단단한 물체로 보고, **얼굴에는 여러 개의 기준점이 있고 그 기준점들이 3D에서 이런 모양인데 카메라에서 보니까 2D로 이렇게 보인다를 계산하여 물체 전체가 어떻게 회전했는가를 계산**함
    
    얼굴의 원점으로 잡은 코([0,0,0]) 는 카메라 원점이 아닌 얼굴 모델의 원점으로, 
    **Head Pose는 얼굴의 특정 랜드마크 하나를 기준으로 계산되는 것이 아니라 여러 랜드마크로 정의된 얼굴 전체를 하나의 강체로 가정하고 해당 얼굴 모델 좌표계가 카메라 좌표계에 대해 얼마나 회전했는지를 추정함**
    
1. 얼굴 랜드마크로 얼굴의 3D 방향을 추정
2. 그 얼굴이 카메라 좌표계에서 얼마나 회전했는지 계산
3. 그 회전 중
    - **yaw = 좌우 회전  ←**  이 값을 사용
    - pitch = 상하 회전
    - roll = 기울기

| yaw 값 | 카메라의 판단 |
| --- | --- |
| yaw < 0 | **카메라 기준 왼쪽을 봄** |
| yaw ≈ 0 | **카메라를 정면으로 봄** |
| yaw > 0 | **카메라 기준 오른쪽을 봄** |

정면을 가만히 응시하고 있어도 매 프레임마다 ±2~5° 정도 흔들림은 존재하기 때문에 실제 코드에서는 **정면 구간**을 설정할 수 있음

```jsx
YAW_LEFT_TH  = -20.0
YAW_RIGHT_TH =  20.0
```

```jsx
def yaw_to_direction(yaw):
if yaw <= -20:
return "LEFT"
if yaw >= 20:
return "RIGHT"
return "FRONT"
```

| yaw 범위 | 판정 |
| --- | --- |
| yaw ≤ -20° | LEFT |
| -20° < yaw < +20° | FRONT |
| yaw ≥ +20° | RIGHT |

PC에서 APK 빌드 → APK 파일을 폰으로 옮김 → 폰에서 설치 → 앱 실행

### 1. PC 에서 APK 만들기 (Flutter)

**프로젝트 위치 예시**

```jsx
C:\WS\flutter_projects\workout_counter_mobile
```

1. **기존 빌드 파일 정리**

```jsx
flutter clean
```

1. **패키지 다시 받기**

```jsx
flutter pub get
```

1. **Release APK 빌드**

```jsx
flutter build apk --release
```
