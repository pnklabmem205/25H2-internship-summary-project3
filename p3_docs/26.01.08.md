### READY 조건

### 핵심 지표

**refLen0 (기준 길이)**

- refSample = |knee_y - shoulder_y|

**hipStandY (서 있을 때 엉덩이 y)**

- 서 있을 때 힙 y좌표 평균

**ankleStandY (서 있을 때 발목 y)**

- 서 있을 때 발목 y좌표 평균

---

1. **poseOK: 포즈가 제대로 잡히나?**
    - 캘리 전에는 몸 전체가 잘 보여야 함
        - coreVis(어깨/힙/무릎) + ankVis(발목) visibility가 threshold 이상이어야 함
2. **standOK: 진짜 서 있는 자세인가?**
    - 엉덩이가 무릎보다 충분히 위에 있어야 서 있다고 인정
3. **stableOK: 몇 프레임 동안 흔들리지 않고 안정적인가?**
    - stableWindow = 8 프레임동안
        - hip y 변화폭
        - refSample 변화폭
        - ankle y 변화폭
        - 이 세가지 변화가 크면 stableOK=false

**위 세 가지 조건이 getHoldFrames = 6 프레임 연속 맞으면 캘리브레이션 시작**

### CALI 조건

**3초 동안 모은 프레임이 최소 10개 이상일 때 기준 자세 데이터를 모아서 평균 냄**

1. **refSample을 계속 모음 (사람 크기 기준)**

```dart
refSample = |knee_y - shoulder_y|
_sumRef += refSample
```

- 화면에서 **어깨 위치**랑 **무릎 위치**가 얼마나 떨어져 있냐를 재는 값
- 사람 전체 크기(키 느낌)가 화면에서 얼마나 크게 보이는지 나타냄

---

1. **hip(y)을 계속 모음 (서있을 때 엉덩이 위치 기준)**

```dart
_sumHip += midHip.y
```

- 서있을 때 엉덩이 y값을 계속 적어두는 것
- 운동 중 엉덩이 y가 서있을 때 엉덩이 y(hipStandY)보다 얼마나 내려갔는지를 계산하기 위함

---

1. **ankle(y)을 계속 모음 (서있을 때 발목 위치 기준)**

```dart
_sumAnk += midAnk.y
```

- 서있을 때 발목 y값을 계속 적어두는 것
- 발이 들렸다/점프했다 같은 걸 확인할 때 또는 사람의 자세 안정성 참고할 때 기준으로 사용

---

1. **nCalib++**

```dart
_nCalib++
```

- 지금까지 몇 프레임 데이터를 모았는지 카운트

### **CALI가 끝나면 저장되는 값**

**3초 동안 모아둔 값을 평균(=총합 / 개수) 해서 기준값으로 저장**

1. **refLen0 (내 화면에서의 ‘키 기준’)**

```dart
refLen0 = _sumRef / _nCalib
```

- 서 있을 때, 평균 어깨~무릎 거리

---

1. **hipStandY (서 있을 때 엉덩이 기준)**

```dart
hipStandY = _sumHip / _nCalib
```

- 서 있을 때, 화면에서의 평균 엉덩이 y

---

1. **ankleStandY (서 있을 때 발목 기준)**

```dart
ankleStandY = _sumAnk / _nCalib
```

- 내가 서 있을 때, 화면에서의 평균 발목 y

### COUNT 로직

**캘리브레이션이 끝나면 상태 전이(FMS)로 버피를 판단**

1. STAND (서있음)
2. DOWN (쪼그려 앉음/내려감)
3. PLANK (플랭크 자세)
4. BACK (다시 일어남)

### 핵심 지표

1. **hipDrop**

```dart
hipDrop = (midHip.y - hipStandY) / refLen0
```

- 서 있을 때 hipDrop ≈ 0
- 내려가면 hipDrop 증가 (엉덩이가 아래로 내려가서 y가 커짐)
- **엉덩이가 얼마나 내려갔나를 키로 정규화한 값**

---

1. **angleHip (힙 각도)**

```dart
angleHip = angle(midSh, midHip, midKnee)
```

- 어깨-힙-무릎 세 점 각도
- 몸이 펴져 있으면 각도가 큼(170~180 근처)
- 숙이면 작아짐
- **몸이 펴졌는지/접혔는지  판단하는 각도**

### 상태 전이 조건

**1) STAND → DOWN**

```dart
isDown = hipDrop >= downHipDropMin  // 기본 0.45
```

- 엉덩이가 충분히 내려가면 DOWN 진입

---

**2) DOWN → PLANK**

```dart
plankEnter = (angleHip >= 160) && (hipDrop >= 0.10) && (hipDrop <= 0.80)
```

- 몸이 펴진 형태(각도 큼) + hipDrop 범위가 맞으면 플랭크로 들어갔다로 인정
- 조건이 3프레임 연속 맞아야 진짜 전이

---

**3) PLANK → BACK**

```dart
plankKeep = (angleHip >= 145) && hipDrop 범위 유지
backSig = (!plankKeep) && (hipDrop >= hipDropBackMin || angleHip <= angleBackMaxDeg)
```

- PLANK 상태에서 플랭크 유지 조건이 깨지면 backSig가 켜지고 BACK으로 넘어감
- `holdFramesPlankToBack=1`이라 거의 바로 넘어감

---

**4) BACK → STAND (+ COUNT++)**

```dart
isStand = hipDrop <= standHipDropMax  // 기본 0.18
```

- BACK 상태에서 다시 서있는 값으로 돌아오면 STAND로 전이하면서 `count++`
