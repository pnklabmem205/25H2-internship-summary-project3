## v0.4 스쿼트 카운팅 로직

**핵심 아이디어: 
엉덩이(hip)가 서 있을 때 기준 보다 얼마나 내려갔는지를 몸 길이(어깨~무릎 길이) 로 나눠서 %로 만든 다음, 그 %가 임계값을 넘으면  DOWN, 다시 돌아오면 UP & + 카운트**

### 1. 준비 단계: 사람 인식 체크

- 매 프레임마다 LEFT/RIGHT 어깨, 엉덩이, 무릎 6개 landmark의 visibility 최소값을 구함
- `vis_used ≥ 0.5` 이면 이번 프레임 포즈가 믿을만하다고 판단 `(pose_ok = TRUE)`

### 2. 캘리브레이션

- 처음 3초를 서 있는 기준으로 저장해서 사람/거리 달라도 비교 가능하게 만듦
- 3초동안 프레임을 모아서 평균냄
    - hip0_y = 서 있을 때 중앙 hip y 평균
    - ref_len0 = 서 있을 때 (중앙 knee y - 중앙 shoulder y) 평균 = 몸 길이 기준
- 캘리브레이션 끝나면
    - state = UP
    - count = 0
    - `ready = false`로 초기화

### 3. depth % (앉은 정도 %) 계산

- 캘리브레이션이 끝나면 매 프레임마다:

(1) 엉덩이가 내려간 양 (픽셀 대신 y좌표 기준)

- `drop = mid_hip_y - hip0_y`
    - 화면 좌표 특성 상 아래로 갈수록 y가 커짐
    - 앉으면 mid_hip_y가 켜저서 drop 증가

(2) 사람/거리 보정 (정규화)

- `depth_pct = drop / ref_len0`
    - depth_pct = 엉덩이가 내려간 거리 / 몸 길이 (어깨~무릎)
- EMA로 부드럽게
    - `ema_pct = EMA(depth_pct)`
    - 순간 튐/노이즈를 줄이고 안정적으로 임계값 판단

### 4. READY 게이트

- pose_ok가 연속 10프레임 유지되면 `ready = TRUE`

### 5. 상태 머신

- ready 가 TRUE일 때만 동작
- 현재 `state = UP` 인데
**ema_pct ≥ 0.25** 이면 → `state = DOWN`
- 현재 `state = DOWN` 인데
**ema_pct ≤ 0.12** 이면 → `state = UP`, `count+=1`
- UP → DOWN → UP 이 1회

### 6. 포즈 끊김 처리

- 포즈가 안 잡히는 프레임이 MISS_TOL(8)을 넘으면:
    - ready 해제
    - ema 초기화
    
    → 다시 안정적으로 잡힐 때까지 카운트 안함
    

## v0.4 푸쉬업 카운팅 로직

**핵심 아이디어: 
어깨가 baseline (UP 자세)에서 얼마나 내려갔는지를 어깨 너비로 나눠서 거리/체형 영향을 줄이고 그 값이 임계값을 넘으면 DOWN, 다시 돌아오면 UP, + 카운트**

### 1. 사용 관절 & 인식 조건

- 매 프레임마다 MediaPipe에서:
    - 좌/우 어깨 (LEFT/RIGHT_SHOULDER)
    - 좌/우 팔꿈치 (LEFT/RIGHT_ELBOW)
    
    4개의 visibility  중 최소값을 human_vis로 잡음
    
- `human_vis ≥ 0.6` 일 때만 사람이 제대로 잡혔다고 판단하고 진행

### 2. 전체 단계 흐름

**(1) WAIT**

- SPACE 입력 기다림
    - 사람이 잘 보이는 상태 (`human_vis ≥ 0.6`)에서 SPACE를 눌러야 함

**(2) COUNTDOWN** 

- SPACE 누르면 `start_pressed_time` 저장
- 3초 뒤 baseline 잡음

**(3) BASELINE** 

- UP 자세 기준 점을 잡는 단계
- `BASELINE_FRAMES = 10` 동안 `mid_sh_y`(좌/우 어깨 y 평균) 을 보면서 가장 위에 있는 어깨를 `sh0_y` 로 저장
- `sw0 = shoulder_width` 저장
    - 좌/우 어깨 x 차이 → 카메라 거리 보정용 기준

**(4) COUNTING**

- 매 프레임마다 어깨가 얼마나 내려갔는지 계산

(1) 내려간 정도 계산 (정규화) 

- `d = (mid_sh_y - sh0_y) / sw0`
    - UP 대비 어깨가 아래로 내려간 양 / 어깨너비
    - 카메라 거리/사람 크기 보정

(2) EMA로 부드럽게

- `ema_d = EMA(d)`
    - 프레임 튐 방지

### 3. 상태 머신

- UP → DOWN
    - `state == UP` 이고 `ema_d ≥0.30` 이면 DOWN
- DOWN → UP, + 카운트
    - `state == DOWN` 이고 `ema_d ≤ 0.25` 이면 UP으로 바꾸고 count +=1
- UP → 충분히 내려감(0.30) →  DOWN → 충분히 올라옴(0.25) → UP 이 카운트 1회

### 4. 포즈 끊김 처리

- 포즈가 없거나 인식이 불안정한 프레임이 쌓여 `miss>10` 이 되면
`reset_all()` 실행 → WAIT 단계로 돌아감

### 5. 키 조작

- **SPACE**: (WAIT 상태 + 사람 잘 잡힘) → COUNTDOWN 시작
- **R**: 언제든지 초기화(reset_all)
- **ESC**: 종료

## v0.4 크런치 카운팅 로직

**핵심 아이디어:**

**어깨 - 엉덩이 - 무릎 3점으로 엉덩이 각도를 계산해서 굽힘 정도(flex) 로 바꾼 뒤, 최근 움직인 범위 (min~max) 안에서 비율로 임계값 (up_th/down_th)을 만들고 DOWN → UP 이 되면 1회 카운트**

### 1. 사용 데이터 / 인식 조건

매 프레임마다:

- 2D pose_landmarks 로 visibility 체크
    - 어깨/엉덩이/무릎 좌우 6개 중 최소값이 VIS_TH(0.5) 이상이어야 함
- 3D pose_world_landmarks 가 있을 때만 각도 계산 가능

### 2. flex (굽힘 각도) 계산

3D 점:

- A = Shoulder
- B = Hip  ← 각의 꼭짓점
- C = Knee

**(1) raw_angle = ∠(Shoulder–Hip–Knee)**

- `angle_abc_3d(A,B,C)`로 계산
    - 몸이 펴지면 raw_angle 이 180에 가까움
    - 몸을 접으면 raw_angle 이 작아짐

**(2) flex로 변환**

- `flex_raw = 180 - raw_angle`
    - 몸이 펴지면 flex는 0에 가까움
    - 몸을 접으면 flex가 커짐

(3) EMA로 부드럽게

- flex_now = EMA(flex_raw, ALPHA = 0.2)

### 3. 노이즈 필터

(1) `WARMUP_FRAMES = 25`

- 처음 25 프레임 동안은 flex를 모으기만 하고 카운트 안함
    - 초기 자세 잡힘/랜드마크 안정화 시간

(2) `JUMP_DEG = 20`

- 이전 flex 와 비교해서 abs(flex_now - prev_flex) > 20 이면 그 프레임은 skip_state_update = TRUE
    - 갑자기 튄 프레임(노이즈)을 카운트에 반영하지 않음

(3) `HOLD_UP / HOLD_DOWN = 3`

- 임계값을 한 번 넘었다고 상태 바꾸지 않고 3 프레임 연속 만족해야 상태 변경
    - 깜빡임/경계값 흔들림 방지

### 4. 최근 움직임 범위 (window) 만들기

매 프레임마다:

- `flex_min = min(flex_min, flex_now)`
- `flex_max = max(flex_max, flex_now)`
- 최근 구간에서의 최소 굽힘 / 최대 굽힘을 계속 갱신함

### 5. 운동으로 인정할 지 검사: swing

- `swing = flex_max - flex_min`
    - swing 이 너무 작으면 운동으로 카운트 X
    - `swing ≥ MIN_SWING_DEG (12)` 일때만 진짜 크런치 가능성으로 판단

### 6. 임계값 비율로 자동 생성

- 고정 각도가 아닌 사람마다 범위가 다를 수 있기 때문에 최근 범위 (swing)에서 비율로 임계값을 만듦
    - `up_th = flex_min + swing * P_UP`
        - **up_th는 최소 굽힘에서 35%만큼 올라온 지점**
    - `down_th = flex_max - swing * P_DOWN`
        - **down_th는 최대 굽힘에서 35% 내려온 지점**

### 7. 상태 머신

- state는 DOWN 상태에서 시작

(1) DOWN → UP 

- flex_now ≥ up_th 를 연속 3 프레임 만족하면 state = UP  , count +=1
- flex_min, flex_max 현재 값으로 리셋 (새 구간 시작)
- **누워있다가 상체를 올리는 동작이 1회로 카운트**

(2) UP → DOWN 

- flex_now ≤ down_th 를 연속 3 프레임 만족하면 state = DOWN
- flex_min, flex_max 현재 값으로 리셋 (새 구간 시작)
- 다시 누운 상태로 돌아가야 다음 카운트가 가능

### 8. 포즈 끊김 처리

- 랜드마크가 MISS_TOL(8) 프레임 이상 안 잡히면
    - ema_flex, prev_flex, flex_min/max, hold, warmup 초기화
    - `state = DOWN`으로 복귀
