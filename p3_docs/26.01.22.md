## YOLO Pose + FaceMesh 기반 실시간 인원·영역 인식 실험

### 0. 실행 준비

**가상 환경 준비**

```jsx
python -m venv .venv   // 설치
.\.venv\Scripts\activate   // 실행
```

**필수 패키지 설치**

```jsx
pip install --no-cache-dir mediapipe==0.10.21 opencv-contrib-python==4.11.0.86 numpy==1.26.4
pip install opencv-python numpy mediapipe ultralytics

```

### 1. 얼굴 방향 실험 (FaceMesh + solvePnP)

https://github.com/pnkmem432/HEADPOSE/blob/main/headpose_webcam_direction.py

https://drive.google.com/drive/folders/1UalMahD9Hub1YRj1WhofkOEyOcMCvGPS?hl=ko — `데모_HeadPose Direction.mp4` 참고 

### 목표

- 얼굴 방향 (좌/정면/우) 트래킹
- FaceMesh 랜드마크 10개 → solvePnP → yaw/pitch/roll 계산
- yaw를 입계값으로 방향 분류
    - yaw < -15° → RIGHT
    - yaw > +15° → LEFT
    - 그 사이는 FRONT

### 진행 과정

1. 웹캠 프레임 수집
2. FaceMesh로 얼굴 랜드마크 10 추출
    - 코, 턱, 눈, 볼 등
3. 3D 모델 포인트와 2D 이미지 포인트 매칭
4. `cv2.solvePnP` 로 회전벡터 rvec
5. rvec → 회전행렬 → euler(yaw/pitch/roll)
6. yaw 이동 평균 → 방향 텍스트 표시

### 2. 4분할 Zone + YOLO Pose + FaceMesh

https://github.com/pnkmem432/HEADPOSE/blob/main/face_body_pose.py

https://drive.google.com/drive/folders/1UalMahD9Hub1YRj1WhofkOEyOcMCvGPS?hl=ko — `4분할 Zone + YOLO Pose + FaceMesh.mp4` 참고

### 목표

- YOLO Pose로 사람을 검출 + 스켈레톤 추정 + 트래킹 ID 확보
- 화면을 4분할(Zone 1~4) 해서
    - 사람마다 어느 Zone 에 있는지 라벨링
    - Zone 별 인원 수 카운트 출력
- FaceMesh 사용하여 얼굴 랜드마크 점 + 얼굴 박스 표시

### 진행 과정

1. 웹캠 프레임 수집
2. Zone 기준선 설정
    - 화면의 x,y를 각각 `ZONE_X_SPLIT`, `ZONE_Y_SPLIT`로 2분할
    - 트랙바로 split 지점을 실시간 조절
    - `draw_zones()`가 십자 선 + ZONE1~4 텍스트 표시
3. YOLO Pose + Tracking
    - 출력: 사람 bbox, keypoints(17개)
4. PersonSlotManager로 사람 번호(person1~) 유지
    - track id가 바뀌거나 누락될 수 있어서 박스 IoU 기반으로 슬롯 재할당 + TTL(2초)로 사람 이탈 처리
5. Zone 판정
    - 발 위치로 Zone 판단 → `get_foot_point()`
        - 가능하면 발목 키포인트(15/16) 중 더 아래쪽(y가 큰 값) 사용
        - 발목이 불안정하면 bbox 하단 중앙 fallback
    - 발 좌표가 어느 사분면에 속하는지로 zone 결정
6. 시각화
    - bbox / 라벨 / 스켈레톤 / 키포인트 색을 Zone 색으로 통일
    - 하단에 `Z1: n Z2: n ...` 출력
7. FaceMesh 오버레이
    - 얼굴 랜드마크 일부 점 찍기
    - face bbox 그리기 + FACE# 라벨

### 3. 매트 ROI + YOLO Pose + 얼굴 방향

https://github.com/pnkmem432/HEADPOSE/blob/main/zone.py

https://drive.google.com/drive/folders/1UalMahD9Hub1YRj1WhofkOEyOcMCvGPS?hl=ko — `데모_PNKS-Human Body Detection.mp4` 참고

### 목표

- 상부 카메라/원근 왜곡 환경에서 화면 4분할만으로 Zone을 나누면 부정확
- 검은색 매트 영역을 4점으로 찍어 보정하고, 그 보정된 매트 이미지에서 흰 테이프 십자(가로/세로 라인)를 자동 검출해서 진짜 Zone 기준선을 얻음
- 사람의 발 위치(프레임 좌표) → 매트 좌표로 변환 → 십자 기준으로 Zone 판정
- 얼굴 방향(solvePnP)까지 합쳐서 person 라벨에 (Zone + face 방향) 표시

### 진행 과정

1. 매트 캘리브레이션
    - 프레임에서 찍힌 매트를 평면처럼 펴기
    - 방법: ‘M’ 키 누름 → 매트 4점을 클릭
        - ‘R’ 키 → 전체 리셋
2. Tape 캘리브레이션
    - 워핑된 매트 이미지에서 흰 테이프 가로/세로 라인을 찾아 교차점을 구함
    - 방법: ‘C’ 키 누름 → 현재 프레임을 매트 좌표로 변환 → Zone 경계선을 기준ㄴ으로 매트 4분할
3. YOLO Pose + 사람 Zone 판정 
    - 발 위치를 계산 하여 매트 좌표로 투영한 후 십자 기준으로 Zone 결정
    - Zone 확정된 사람만 그림
4. 얼굴 방향 추정은 아직 구현이 되지 않은 상태
