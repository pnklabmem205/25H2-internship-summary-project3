**<ccm_tuner 폴더 구조>**

| 항목 | 내용 |
| --- | --- |
| **kfold_N100, N200, N300** | K-Fold 방식으로 실험한 결과 폴더. 각 N(데이터 수)에 따라 개별 저장됨 |
| **shuffle_N{N}_tv{ratio}** | Shuffle(split) 방식 실험 결과. Train:Valid 비율(tv_ratio)에 따라 생성됨 |
| **trial_0 ~ trial_4** | 하이퍼파라미터 탐색 중 수행된 개별 시도(Trial). 각 trial마다 학습 결과 및 성능 지표가 저장됨 |
| **trial.json** | 각 trial에서 선택된 하이퍼파라미터 값과 성능 기록(json 형태) |
| **oracle.json** | 전체 튜너(탐색기)의 상태 및 탐색 공간(optimizer, lr, dropout 등) 정의. 즉, 어떤 조합을 얼마나 탐색했는지 기록됨 |
| **tuner0.json** | 비어있음 (최신 Keras Tuner 버전에 따름) |
