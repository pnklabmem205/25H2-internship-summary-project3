- 여전히 C 값 낮음 (흰 색 기준 30000정도 나와야 안정)
- 빨간 색만 오차가 조금 줄고, 파랑,  초록은 오차가 더 커짐
    - 이상적인 RGB 필터라면 R 필터는 빨강 파장(600~700nm)만, G 필터는 초록 파장(500~600nm)만, B 필터는 파랑 파장(400~500nm)만 받음
    - 하지만 TCS34725의 데이터시트를 참고해보면 R 채널은 비교적 좁게 600~700nm만 잘 잡지만 G 채널과 B 채널은 상대적으로 광대역으로 잡아 스펙트럼 간섭이 심함
    - GAIN 을 올리는 건 센서 출력 신호를 증폭하는 것이기 대문에 원래 잘 잡히던 신호도 커지지만, 같이 들어온 간섭 신호도 똑같이 커지기 때문에 오차가 커진 것으로 예상

- Gain을 크게 올려도 C 값이나 정확도가 좋아지지 않음

## TCS34725 센서 – Integration Time & Gain

## Integration Time(적분 시간)

| Integration Time | 설명 |
| --- | --- |
| 2.4ms | 가장 짧음, 매우 밝은 환경에서 빠른 측정용 |
| 24ms | 밝은 환경, 빠른 측정 가능 |
| 50ms | 일반적인 실내 환경 |
| 101ms | 조금 어두운 환경, 측정 안정성 증가 |
| 154ms | 어두운 환경, RGB 안정적 |
| 700ms | 가장 긴 시간, 아주 어두운 환경, 측정 속도 느림 |

- 센서가 빛을 누적해서 측정하는 시간
- Integration Time ↑
    
    → 센서가 빛을 더 오래 누적 
    
    → C값 증가, RGB 안정화
    
- 단점 : 측정 속도 ↓

## Gain(감도조정)

| Gain 설정 | 설명 |
| --- | --- |
| 1x | 가장 낮음, 밝은 환경용 |
| 4x | 일반 환경 |
| 16x | 조금 어두운 환경 |
| 60x | 아주 어두운 환경 |

- ADC에 들어오는 신호를 몇 배로 증폭할지
- Gain을 올리면 **센서가 적은 빛도 크게 증폭**
    
    → 낮은 C값에서도 안정적인 값 확보 가능
    
- 단점: 밝은 색에서 포화 발생 가능
