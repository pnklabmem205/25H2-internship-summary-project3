## **TensorFlow 방식 패치 실험**

- https://github.com/Work-DX/skin-color-measuring-by-color-sensor/tree/main/BLE/src/train_ccm_skintone
    
    ### 코드 구조
    
    1. **데이터 읽기** → 엑셀/CSV에서 색상 패치 정보 가져오기
    2. **전처리** → 잘못된 값/보정용 패치(calibration) 제외, 라벨 정리
    3. **샘플 나누기** → 학습(train) / 검증(valid) 데이터 분리
        - Dark(어두운 색) 부분은 더 자주 뽑히도록 비율 조정
    4. **모델 만들기** → Dense(3) 레이어 1개 (= 선형 공식)
    5. **학습하기** → Adam 최적화, MAE(평균 절대 오차) 기준, EarlyStopping으로 안정화
    6. **평가하기** → MAE, ±10% 성공률, 0으로 무너짐 여부
    7. **반복하기** → 여러 번 랜덤으로 돌려서 가장 좋은 결과 고르기
    8. **결과 저장** → 모든 기록과 최종 CCM을 엑셀로 내보내기
    
    ---
    
    ### 주요 모듈 설명
    
    ### 1) 데이터 처리 부분
    
    - **load_master()** :
        - 엑셀/CSV에서 데이터를 불러옴
        - 필요한 칼럼(`R,G,B, rs_med,gs_med,bs_med`) 확인
        - 잘못된 값은 제거
        - Bucket 이름 통일 (예: Medium → Med)
    - **calibration_mask()** :
        - 회색카드, 칼라체커 같은 보정용 샘플을 찾아내서 **학습에서는 제외**
        - 검증에는 포함될 수 있음
    
    ---
    
    ### 2) 샘플링 부분
    
    - **Scheme A** : Light/Med/Dark 비율을 정해놓고 뽑음 (Dark는 0.45로 강화)
    - **Scheme B** : 9개 Bucket을 균등하게 뽑은 후 Dark만 추가로 더 뽑음
    
    → 이번 실험에서는 **Scheme A** 사용
    
    ---
    
    ### 3) 모델 부분
    
    - **build_linear_ccm()** :
        - Dense 레이어 1개짜리 모델 생성
        - 입력: 센서 RGB(3개) → 출력: 목표 RGB(3개)
        - NonNeg 옵션을 켜면, 가중치가 음수가 되지 않도록 제약
    
    ---
    
    ### 4) 지표 계산 부분
    
    - **MAE (평균 절대 오차)** : 평균적으로 얼마나 틀렸는지
    - **±10% 성공률** : 예측이 실제 값의 ±10% 안에 들어간 비율
    - **Zero collapse** : 예측이 0 근처로 무너진 횟수 (특히 Dark 영역 문제 확인용)
    
    ---
    
    ### 5) 학습 부분
    
    - **run_one_rep()** :
        - 학습/검증 데이터 나누고 모델 학습
        - EarlyStopping(patience=80) → 80번 동안 개선 없으면 중단
        - 최종 성능(MAE, 성공률 등)과 CCM 행렬(W|b) 반환
    - **run_experiment()** :
        - 전체 실험 루프
        - 여러 번 반복(repeats=10)해서 랜덤 분할 효과 줄이고
        - 가장 성능 좋은 rep 선택
        - 모든 결과와 최종 CCM을 엑셀로 저장
    
    ---
    
    ### 6) 실행 부분
    
    - `main()` 함수 → 커맨드라인에서 옵션 주고 실행할 수 있도록 구성
        - `-in_xlsx` : 데이터 경로
        - `-train_N` : 학습에 쓸 샘플 개수
        - `-repeats` : 몇 번 반복할지
        - `-nonneg 1` : 음수 금지 여부
        - `-epochs 800`, `-patience 80` : 학습 세부 설정
        - `-out_prefix` : 결과 저장 파일명 접두어

### Tensorflow 방식 패치 실험 - 핵심 요약

- 딥러닝(Dense 1개, TensorFlow 사용)은 **선형회귀보다 전반적으로 더 좋은 성능**을 보임
- **평균 오차(MAE_avg)**: 대부분의 경우 딥러닝이 동일하거나 더 낮음
- **±10% 성공률**: 딥러닝이 **2~3배 이상 개선**, 특히 훈련 패치 80개일 때 성능이 크게 향상됨
    - 예) 100패치(80/20): 선형회귀 15.8% → 딥러닝 40%
    - 예) 120패치(80/20): 선형회귀 15% → 딥러닝 27.5%
- **Dark 보강 효과**:
    - 선형회귀는 Dark +20에서 성능 악화
    - 딥러닝은 Dark +20에서도 성능이 꾸준히 개선됨 → 과적합에 덜 민감
- **결론**: 선형회귀는 단순하고 안정적이지만 **딥러닝 방식이 오차도 줄이고 성공률도 올리는 데 더 효과적**

## 1. 실험 배경

- 기존: **선형회귀 기반 CCM**
- 현재: **딥러닝(TensorFlow) 기반 CCM**
    
    → 동일한 데이터셋과 샘플링 프로토콜로 비교
    

## 2. 딥러닝 모델 구조

- **입력(Input)** : 센서 RGB 값 (rs, gs, bs)
- **출력(Output)** : 목표 RGB 값 (R, G, B)
- **모델** : Dense(3) 레이어 1개 (= 행렬 곱 + 바이어스)
    - 수식:
        
        $\begin{bmatrix}R\\G\\B\end{bmatrix} =
        W \cdot \begin{bmatrix}r_s\\g_s\\b_s\end{bmatrix} + b$
        
    - $W$: 3×3 가중치 행렬
    - $b$: 3×1 바이어스
    - 합쳐서 **3×4 CCM**이 됨

## 3. 학습 방식

- **데이터셋** : 100 / 110 / 120 패치 (Light, Med, Dark × Warm, Neutral, Cool)
- **샘플링 전략 (Scheme A)** : Dark 구간을 더 많이 뽑도록 가중치 강화 (L/M/D = 0.27 / 0.27 / 0.45)
- **훈련/검증 비율** : Train_N = 20 / 60 / 80 (Validation은 나머지)
- **학습 설정** :
    - Epochs = 800
        - **뜻**:
            - Epoch은 전체 데이터를 한 번 다 보는 것을 뜻함
            - Epochs=800이면 → **데이터를 800번 반복해서 학습**한다는 뜻
        - **왜 필요한가**
            - 컴퓨터는 한 번만 보면 충분히 배우지 못하고 여러 번 반복하면서 점점 정답에 가까워질 수 있음
        - **800으로 설정한 이유**
            - 적은 횟수(예: 100번)로 하면 덜 배울 수 있고, 너무 많은 횟수(예: 5000번)는 시간 낭비일 수 있음
            - 800은 충분히 오래 돌리면서도 너무 과하지 않은 적당한 값이라 생각
            - 실제로는 Early Stopping이 있어서 꼭 800까지 안 가고 중간에 멈출 수도 있음
    - Early stopping = patience 80
        - **뜻**:
            - 학습하다가 **더 이상 좋아지지 않으면 멈추라는 규칙**
            - 여기서 patience=80 → **80번 동안 성능이 더 좋아지지 않으면 중단**한다는 뜻
        - **왜 필요한가**
            - 오래 학습하면 오히려 과적합되어 새 데이터에 성능이 떨어질 수 있음
            - Early stopping을 통해 방지할 수 있음
        - **왜 80으로 했어?**
            - 10~20으로 하면 너무 빨리 끊겨서 잠깐 성능이 안 좋아졌다가 다시 좋아지는 순간을 놓칠 수 있음
            - 100 이상으로 하면 기다림이 너무 길어져서 시간 낭비가 될 수 있음
            - **80은 적당히 여유 있는 값이라고 생각**
    - Optimizer = Adam
        - **뜻**:
            - Optimizer는 컴퓨터가 얼마나, 어떻게 가중치를 조정할까? 를 정하는 방법
        - **Adam?**
            - Adam은 빠르면서도 안정적이라 제일 많이 쓰는 기본값
            - 현재 실험에선 복잡한 딥러닝이 아닌 단순 선형층을 사용하지만 빠르고 안정적인 학습이 필요함
    - Loss = MAE(평균 절대 오차)
        - **뜻**:
            - Loss는 얼마나 틀렸는지를 숫자로 보여주는 지표
            - MAE는 단순히 **예측값과 정답의 차이의 평균**
            
            예시:
            
            - 정답 100, 예측 90 → 오차 = 10
            - 정답 200, 예측 220 → 오차 = 20
                
                평균 오차 = (10 + 20) / 2 = 15
                
        - **왜 MAE를 사용했는지**
            - 다른 방법(MSE)은 큰 오차에 너무 민감해져서 불안정해질 수 있음
            - MAE는 단순하고 직관적이라 **평균적으로 몇 값 차이 나는지** 바로 알 수 있다는 장점이 있음

## 6. 결론

### **선형 회귀**

- **개념**
    - 하나의 수학 공식으로 센서 RGB → 목표 RGB를 한 번에 계산하는 방식
    - 예: $y = Wx + b$
    - 한 번에 답을 구하는 대신 답이 틀리면 수정할 방법이 제한적임
- **특징**
    - 단순하고 안정적인 방식이라 결과가 크게 흔들리지 않음
    - 훈련에 사용하는 패치 수(20 → 60 → 80)가 늘어날수록 평균 오차(MAE_avg)가 조금씩 줄어듦
- **Dark 패치 보강 효과**
    - Dark 패치를 **+10개(=110패치)** 추가했을 때 ±10% 성공률이 눈에 띄게 좋아짐
    - 하지만 +20개(=120패치)까지 늘리면 오히려 성능이 나빠짐 (데이터 분포가 한쪽으로 치우치면서 모델이 균형을 잃음)

### **딥러닝 (Dense 1개 레이어)**

- **특징**
    - 딥러닝이라고 해도 이번에는 Dense 레이어 1개만 사용 → 사실상 **선형 보정**과 같은 구조
    - 차이는 **훈련 방식** (Optimizer=Adam, Loss=MAE, Early stopping 등)을 딥러닝 프레임워크로 처리했다는 점  → 데이터를 여러 번 반복해서 조금씩 답을 수정함
- **성능 경향**
    - 전체적으로 **±10% 성공률이 크게 증가**
    - 일부 경우(예: 100패치, 훈련 60개)에서는 MAE_avg가 선형회귀보다 조금 나빠졌지만
        
        대부분의 경우에서는 오히려 **MAE_avg도 더 낮고 성공률도 높음**
        
- **눈에 띄는 결과**
    - **훈련 패치를 많이 쓸 때(Train=80)** 딥러닝이 확실히 더 좋은 결과를 보임
        - 100패치 80/20 → MAE 5.67% → **5.45%**, 성공률 15.8% → **40%**
        - 120패치 80/20 → MAE 5.92% → **5.10%**, 성공률 15% → **27.5%**
    - 즉, 딥러닝이 데이터가 많아질수록 성능을 더 잘 끌어올림

### 💡 왜 딥러닝이 더 좋은 결과를 보일까?

### 1) **최적화(Optimizer)의 차이**

- **선형회귀**는 보통 최소제곱법(LS) 같은 고정된 방식으로 한 번에 해를 구함
- **딥러닝**에서는 **Adam Optimizer**를 사용했는데 이 방식은 **데이터를 조금씩 보면서 반복적으로 가중치를 조정함**
- 이 과정에서 단순 최소제곱 해보다 **MAE 기준으로 더 잘 맞는 지점을 찾아갈 수 있음** → 특히 노이즈가 있는 데이터에서 강점

---

### 2) **Loss 함수 차이 (MSE vs MAE)**

- 선형회귀는 보통 MSE(제곱 오차)를 최소화 → 큰 오차에 매우 민감
- 이번 딥러닝은 **MAE(평균 절대 오차)**를 최소화 → 전체적으로 평균적으로 얼마나 틀렸는지에 더 집중
- 그래서 극단적으로 많이 틀린 샘플(Outlier)의 영향을 덜 받고 **실제 평균 오차가 더 작아질 수 있음**

---

### 3) **정규화/제약 조건의 유연성**

- 딥러닝에서는 **NonNeg 제약**(가중치가 음수가 안 되도록) 같은 걸 쉽게 걸 수 있음
- 이런 제약 조건이 센서–색 보정 문제에 맞으면 선형회귀보다 더 물리적으로 타당한 해를 만들 수 있음

---

### 4) **훈련 과정에서의 안정성**

- 딥러닝 학습은 **Epoch 반복 + Early Stopping**을 통해 조금이라도 더 나은 해를 찾으면서도 **성능이 더 좋아지지 않으면 자동으로 멈추는 기능**이 있음
- 선형회귀는 이런 조율 과정이 없이 한 번에 해만 주기 때문에 특정 분포(특히 Dark 강화된 경우)에서는 딥러닝 쪽이 더 안정적 결과를 낼 수 있음
