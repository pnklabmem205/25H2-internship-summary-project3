## 1️⃣ 실험 목적

이 실험은 **센서가 측정한 RGB(rs, gs, bs)** 값을 **표준 컬러카드 RGB(R, G, B)** 로 보정하는

**Color Correction Matrix (CCM, 3×4)** 를 **TensorFlow 기반 학습**으로 추정하는 실험

기존에는 수학적으로 한 번에 계수를 구하는 **선형회귀(CCM 공식법)** 을 사용했지만,

이번에는 **딥러닝 기반 Dense 모델**을 적용하여 실험함

| 비교 항목 | 기존 CCM(선형회귀) | TensorFlow CCM |
| --- | --- | --- |
| 계산 방식 | 수학 공식 한 번 계산 | 반복 학습(Gradient Descent) |
| 오차 기준 | 제곱 오차(L2) | 절대 오차(L1, MAE) |
| 안정성 | Dark에서 0으로 꺼지는 현상(Zero-collapse) 있음 | 비음수 제약으로 완화 |
| 확장성 | 단순함(빠름) | 비선형 확장 가능 |
| 과적합 위험 | 적음 | 존재(특히 데이터 적을 때) |

## 3️⃣ 데이터 분할 방식

### 🔹 기존 문제점

- Train, Valid, Test 모두 **랜덤으로 매번 나뉘었음**
- 실험마다 샘플 구성이 바뀌어 **비교가 불가능**
- 일부 패치는 한 번도 평가되지 않음

---

### 🔹 개선된 분할 원칙

**Step 1. Calibration 샘플 완전 제외 (10)**

- 흰색/검정(기준색) 등 극단적 패치는 학습/검증/테스트에서 제외
- Calibration 샘플 활용
    
    
    | 단계 | 이름 | 활용 목적 | 설명 |
    | --- | --- | --- | --- |
    | **1️⃣ 입력 보정 (Pre-Calibration)** | 센서값 교정 | 센서가 기본적으로 어둡거나 밝게 읽는 경향을 보정 | 센서 RGB → “보정된 입력 RGB”로 변환 |
    | **2️⃣ 출력 점검 (Post-Evaluation)** | 학습 후 검증 | 모델이 흰색/검정/중간 회색을 얼마나 정확히 예측하는지 확인 | 모델의 전체 톤 밸런스 평가 |
    | **3️⃣ 오프셋 추정 (Offset Correction)** | 데이터 전체 보정 | Calibration 예측오차를 기준으로 전체 결과에 offset 보정 | 예: 전체 예측에 +ΔR, +ΔG, +ΔB 적용 |

**Step 2. Test Set 고정 (20)** 

- Brightness 구간(L/M/D)이 고르게 포함되도록 20개 선택
- 이후 실험(데이터 100, 200, 300 등)에서도 **항상 같은 Test 세트 사용**

 **Why?**

> Test를 고정해야 “데이터가 많아져서 성능이 좋아진 것인지”를 공정하게 비교할 수 있다.
> 
> 
> 예를 들어,
> 
> - 100개 실험에서는 Test에 쉬운 샘플이 많고
> - 200개 실험에서는 어려운 샘플이 많다면
>     
>     성능이 좋아진 건 “데이터 덕분인지”, “Test가 쉬워서인지” 구별할 수 없다.
>     
> 
> 그래서 **Test는 고정(진짜 시험문제)**,
> 
> **Train/Valid만 K-Fold로 돌려 학습 안정성 검증** 하는 게 가장 공정하다.
> 

**Step 3. Train+Valid 구성 (Stratified K-Fold)**

- 남은 500여 개를 **K-Fold 교차 검증(K=5~10)**
- 이렇게 하면 **모든 샘플이 한 번씩 검증에 포함되어 공정성 확보**
- 예시:
    - 100 실험: **총 100 = (Train+Valid 100) + Test 20**
    - 200 실험: **총 200 = (Train+Valid 200) + Test 20**
    - 300 실험: **총 300 = (Train+Valid 300) + Test 20**

## 4️⃣ 모델 구조

| 항목 | 내용 | 설명 |
| --- | --- | --- |
| **입력층 (Input Layer)** | 3 (rs, gs, bs) | 센서로부터 측정된 RGB 입력값 |
| **은닉층 (Hidden Layers)** | Dense(16, relu) → Dense(8, relu) | 센서의 비선형 관계(조명·피부톤 등) 학습 |
| **출력층 (Output Layer)** | Dense(3, activation=None) | 보정된 RGB 출력 (ReLU 제거 → 0으로 꺼짐 방지) |
| **활성화 함수 (Activation)** | ReLU | 색 변화의 비선형 패턴 학습에 유리 |
| **비음수 제약 (Nonneg Constraint)** | -nonneg 1 (옵션) | 가중치가 음수가 되지 않도록 제한 (색 반전 방지) |
| **평가 지표 (Metrics)** | MAE_R/G/B, MAE_avg, ΔE, ±10% 성공률, Zero-collapse 비율 | 색상별 오차·지각적 차이·안정성 종합 평가 |
| **정규화 (Normalization)** | StandardScaler (입·출력 모두) | 입력과 출력의 범위를 맞춰 학습 안정화 |
| **학습률 스케줄링 (LR Scheduling)** | ReduceLROnPlateau(factor=0.5, patience=20, min_lr=1e-6) | 개선이 없을 때 자동으로 학습률을 낮춰 안정화 |
| **EarlyStopping** | patience=40, restore_best_weights=True | 과적합 방지 및 최적 지점에서 자동 종료 |
| **하이퍼파라미터 자동화 (HPO)** | Keras Tuner (Bayesian Optimization)→ Optimizer 종류(Adam/AdamW/RMSprop), 학습률, 은닉층 수·유닛 수, Dropout 비율, Batch Size, EarlyStopping, LR 스케줄링 파라미터 자동 탐색 | 모든 설정을 자동으로 조합·탐색하여 최적의 모델 구성 찾기 |
| **모델 저장 형식** | .h5 / .tflite | PC 및 모바일 환경 모두 호환 가능 |
| **훈련 반복 (Repeats)** | 10회 반복 후 Best 선택 | K-Fold와 병행, 평균 성능으로 안정성 확보 |

---

## 5️⃣ 평가 지표 정리

| 지표 | 의미 | 비고 |
| --- | --- | --- |
| **MAE_R/G/B** | 각 채널 절대 오차 | 낮을수록 좋음 |
| **MAE_avg** | 세 채널 평균 | 전체 성능 지표 |
| **ΔE (CIEDE2000)** | 색 차이(사람 눈 기준) | ΔE < 2면 육안 구분 어려움 |
| **±10% 성공률** | 예측이 정답 ±10% 내 | 높을수록 좋음 |
| **Zero-collapse 비율** | 정답의 R/G/B 중 0이 아닌 값이 예측 결과에서 0으로 떨어진 비율 |  |
| **Train vs Valid MAE 비교** | 과적합 여부 확인 | Valid >> Train이면 과적합 |
| **구간별 MAE 분석 (L/M/D × W/N/C)** | 밝기/톤별 취약 영역 파악 | 취약 구간 원인 추적용 |

## 1️⃣ 딥러닝(DL)이란?

딥러닝은 **컴퓨터가 스스로 데이터를 보고 규칙을 배우는 기술**

- 우리가 공식을 직접 안 알려줘도 **데이터를 많이 보여주면** 컴퓨터가 “이 입력이면 저 출력이 나오겠구나”를 배움

### 예시

| 입력 (센서 RGB) | 출력 (실제 색상) |
| --- | --- |
| (30, 40, 50) | (100, 120, 130) |
| (50, 60, 70) | (150, 160, 170) |
- 데이터가 수백 개 있다면, 딥러닝은 **센서값과 실제 색상의 관계**를 자동으로 배워냄

---

## 2️⃣ 인공신경망(Neural Network)이란?

사람 뇌의 뉴런(신경세포)을 흉내 낸 구조

기본 구조:

```
[입력층] → [은닉층] → [출력층]
```

- **입력층(Input layer)**: 데이터가 들어오는 부분
- **은닉층(Hidden layer)**: 데이터를 해석하고 변환하는 부분
- **출력층(Output layer)**: 우리가 예측하려는 결과를 내는 부분

---

## 3️⃣ Dense(16, relu) 뜻

TensorFlow(Keras)에서 층을 만들 때 이렇게 씀:

```python
from tensorflow.keras.layers import Dense

Dense(16, activation='relu')
```

말로 풀면:

> “뉴런 16개를 가진 층을 만들고, 각 뉴런은 입력값을 받아 relu 함수를 통과시켜 다음 층으로 보낸다.”
> 

---

## 4️⃣ 뉴런(Neuron)과 숫자 의미

### 💡 뉴런(Neuron)이 하는 일

- 작은 계산기 역할
- 입력값 × 가중치 + 편향 → 활성화 함수 적용

예시: 입력값 `(r,g,b) = (30,40,50)`

```
결과 = relu(30*w1 + 40*w2 + 50*w3 + b)
```

- `w1, w2, w3` = 학습하면서 바뀌는 **가중치(weight)**
- `b` = 학습하면서 바뀌는 **편향(bias)**

---

### 🔹 Dense(16, relu)

- **뉴런 16개**
- 입력 3개 → 16개의 계산 → 출력 16개
- 의미: “정보를 16가지 방식으로 해석하겠다”

```
입력(3) → [Dense(16, relu)] → 출력(16)
```

### 🔹 Dense(8, relu)

- 다음 층: 16개의 입력 → 8개의 뉴런 → 8개의 요약 정보
- 의미: “앞 층 특징을 압축”

```
입력(16) → [Dense(8, relu)] → 출력(8)
```

---

## 5️⃣ relu 활성화 함수

- **relu(x) = max(0, x)**
- 음수 → 0, 양수 → 그대로

| 입력 | 출력 |
| --- | --- |
| -3 | 0 |
| 0 | 0 |
| 2 | 2 |
- 역할: “신호를 전달할지 말지 결정”

---

## 6️⃣ 신경망 학습 과정

1. 가중치를 **랜덤**으로 초기화 → 아무것도 모름
2. 예측 → `(예측값 - 실제값)` 차이 계산 (**loss**)
3. 오차를 줄이는 방향으로 가중치를 **조정** → 경사하강법(Gradient Descent) 사용
4. 수백~수천 번 반복 → 모델 점점 똑똑해짐

---

## 7️⃣ 옵티마이저(Optimizer)

- 가중치를 어떻게 바꿀지 결정하는 **두뇌 역할**
- 대표적: `Adam` → 많이 사용됨

---

## 8️⃣ 손실함수(Loss Function)

- 모델이 얼마나 틀렸는지 수치로 알려주는 함수

| 종류 | 설명 |
| --- | --- |
| MAE | 평균 절대 오차 ( |
| MSE | 평균 제곱 오차 ((예측값 - 실제값)² 평균) |
- 색 보정처럼 직관적인 오차는 **MAE**가 좋음

---

## 9️⃣ 학습률(Learning Rate)

- 가중치를 얼마나 빨리 바꿀지 결정
- 너무 크면 발산, 너무 작으면 학습 느림
- 보통: 0.001 ~ 0.0001

---

## 🔟 최종 출력층

- RGB 3개를 예측 → 뉴런 3개

```
입력(8) → [Dense(3, activation=None)] → 출력(R,G,B)
```

## 🧱 전체 예시 구조 (센서 RGB → 보정 RGB)

```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

model = Sequential([
    Dense(16, activation='relu', input_shape=(3,)),  # 센서 RGB 입력 (3)
    Dense(8, activation='relu'),                     # 중간 특징 압축
    Dense(3, activation=None)                        # 출력 RGB (3)
])
```

- 흐름: **센서값 3개 → 은닉층 계산(16 → 8) → 보정된 RGB 3개 출력**
