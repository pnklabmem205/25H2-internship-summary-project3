**Clear(C)** 채널은 “무색(필터 없음)”으로 들어온 전체 빛의 양을 측정한 값 (가시광 전 영역을 다 받음)

- R, G, B 값이 모두 커지면 → 센서가 더 밝은 빛을 받고 있다는 뜻 → Clear 값도 커짐
- R, G, B 값이 모두 작으면 → 빛이 어둡거나 흡수되는 영역 → Clear 값도 작음
- C ≈ R+G+B + (RGB 필터에서 걸러진 부분까지 포함)
- c 값이 너무 작으면 잡음 비율이 커져 결과가 불안정하고, 너무 크면 포화될 가능성이 있기 때문에 30000~50000 정도로 잡는 것이 목표

## RGB Test_Clear(c) 정의

---

## **1. Clear(C) 값 정의**

- **Clear(C) 채널**: 센서에서 R/G/B 필터 없이 들어오는 전체 빛의 강도를 측정한 값.
- 즉, “투명 포토다이오드”처럼 작동하여 모든 가시광선 파장을 거의 그대로 감지함.
- 측정값은 **16비트 정수**: 0 ~ 65535

---

## **2. Clear의 특징**

| 특징 | 설명 |
| --- | --- |
| **전체 밝기 측정** | R/G/B 채널은 각각 특정 파장만 측정하지만, Clear는 모든 가시광 영역을 포함 |
| **RGB 합과 비례** | 일반적으로 RGB 값이 클수록 Clear도 커짐. 다만, R/G/B 분포에 따라 미세 차이 발생 |
| **스펙트럼 의존** | 같은 RGB 합이라도 스펙트럼 분포가 다르면 Clear 값도 달라질 수 있음 |
| **센서 조건 영향** | 통합시간(Integration Time), 게인(Gain), 조명 세기 등에 따라 값이 달라짐 |
| **포화 주의** | 65535 근처 값이면 센서 포화 발생 → 측정 무의미 |
| **잡음 영향** | 너무 낮은 값(몇 백~몇 천)일 경우, 신호 대비 노이즈 비율이 커짐 |

## **3. Clear 값과 RGB의 관계**

- **대체로**: R, G, B 값이 높으면 → Clear 값도 증가
- **주의**: RGB 합과 정확히 일치하지는 않음
    - 예:
        - 노랑: R=200, G=200, B=50 → C ≈ 450 + α
        - 하늘색: R=50, G=200, B=200 → C ≈ 450 + β
    - α ≠ β, 스펙트럼 감도 차이 때문

---

## **4. Clear 값과 프로젝트 적합 범위**

| 대상 | 권장 Clear 범위 | 이유 |
| --- | --- | --- |
| 흰색 레퍼런스(종이 등) | 30,000 ~ 50,000 | 전체 밝기 충분, 포화 여유 확보, SNR 안정 |
| 일반 피부 | 2,000 ~ 15,000 | 피부 반사율 낮음, SNR 확보 가능, 정규화 보정 가능 |
| 피해야 할 영역 | < 500 | 신호 약해 잡음 영향 큼 |
|  | > 62,000 | 포화 위험 |

목표:  흰 종이 기준으로 Clear ≈ 30k~50k 나오도록 통합시간과 게인 조절
