# 🎯 컬러패치 딥러닝 실험 개요

<aside>
📎

📘 **실험 목표**

- 센서 RGB → 타깃 RGB로의 보정 성능을 향상시키기 위해
    
    **데이터 크기(N=100·200·300)** 및 **Train:Valid 비율(50:50→70:30→80:20)** 변화에 따른
    
    **모델의 일반화 성능(MAE·ΔE00)** 을 평가함
    
- **일반 테스트셋**과 **스킨톤 특화 테스트셋** 두 종류의 데이터셋을 사용하여 테스트를 진행함

---

⚙️ **실험 설계 및 주요 개선점**

- **데이터 구조 개선**: Calibration 완전 분리, Test 세트 고정, Stratified K-Fold/Shuffle 분할
- **모델 구조**: Dense(16→8) 비선형 구조 + 비음수 제약(NonNeg)
- **학습 안정화**: StandardScaler 정규화, ReLU + EarlyStopping + LR Scheduler
- **자동 튜닝**: Keras Tuner (Bayesian Optimization, lr·units·dropout 자동 탐색)

---

**📈 추가 분석**

- N 증가(100→200): MAE·ΔE00 전반 감소 → **200 이후 수렴 구간**
- tv_ratio↑ (0.5→0.8): 학습 데이터 증가로 **일반화 성능 향상**
- SelfTest 대비 일반화 손실: **MAE +4~5, ΔE +3~4**

🧠 **종합 해석**

> **데이터 크기 효과**: N=200~300 구간에서 성능 안정화 → 최적 데이터 규모
**비율 효과**: Train 비율 0.7~0.8에서 가장 균형 잡힌 일반화

### 🧩 A. 테스트 방식 (2종)

| 구분 | 목표 | 방식 | 학습/검증 구조 | Test 단계 |
| --- | --- | --- | --- | --- |
| **① K-Fold** | 데이터셋 크기에 따른 **성능/안정성 평가** | Stratified K-Fold  (5-fold)
→ 각 데이터의 **밝기(Vbin)** 와 **톤(Tone)** 조합을 기준으로 층화(Stratified)하여
모든 Fold가 전체 색상 분포를 고르게 대표하도록 구성 | 각 Fold마다 4/5 데이터를 학습(train), 1/5 데이터를 검증(valid)으로 사용
→ Fold마다 중복 없이 전체 데이터를 순환하며 검증 → 모든 샘플이 한 번씩 valid 역할 수행 | 각 Fold 중 최적(`Val_MAE_avg` 최소) 모델을 선택하여  테스트셋(`DL_Test_All` ,`DL_Test_SkinTone`)에 적용 |
| **② Shuffle (비율 테스트)** | **train:valid 비율 변화**에 따른 영향 분석 | Stratified Shuffle Split
→ `strat_key` (예: `"Light-Warm"`, `"Med-Cool"`) 를 기준으로 train/valid 양쪽에 **밝기·톤 조합 비율이 동일**하도록 분할  | 전체 데이터 중 `tv_ratio` 비율로 학습(train), 나머지로 검증(valid) | 각 비율별로 학습 완료 후, 최적 모델을  **테스트셋**(`DL_Test_All`, `DL_Test_SkinTone`)에 적용 |

## 4️⃣ 실험 결과 요약

### 📊 SelfTest (학습/검증용 = 테스트용)

### ① 이론상 기대

- 같은 데이터를 **학습과 테스트에 모두 사용**하면 모델이 데이터를 **완전히 외울 수 있으므로**
    
    MAE=0, ΔE=0 가 되어야 함
    
- 즉, 이론적으로는 오차 없이 완벽히 복제되는 게 정상임

### ② 실제 결과

[selftest_N300_summary.xlsx](attachment:d129f4f9-a005-4221-9700-f5a442a154c1:selftest_N300_summary.xlsx)

| --- | --- | --- |
| MAE_avg | **≈** 9.97 **= 3.91%** | 평균 전체 오차 |
| ΔE00 | **≈** 5.86 | 육안상 색차 |
| ZeroCollapse(%) | 0 | 안정적 출력(완전히 0된 채널 비율) |
- **ΔE00 기준**

### ③ 현실과 이론의 차이가 생긴 이유

| 원인 | 설명 |
| --- | --- |
| **정규화·활성화 효과** | 학습 시 `relu`, `standard scaling` 등으로 인해 일부 값이 클리핑되어 극단적인 색(예: 포화색)에서 완전 복제가 어려움 |
| **수치적 제약** | 1. TensorFlow 연산 과정에서의 부동소수점 오차 등  미세한 차이를 유발할 수 있음
2. 스케일 변환 누적`StandardScaler`로 표준화 → 모델 → 역표준화 → 0~255 스케일 복원 과정에서 여러 번의 반올림/클리핑이 누적돼 255 스케일 기준 0.01~0.1 수준의 차이가 쉽게 생길 수 있음 |
- **정규화·활성화 효과 (gpt)**

### ④ 이 실험이 의미하는 것

- 본 실험은 **딥러닝 모델의 표현 한계**를 확인하기 위한 **외우기(Overfit) 검증** 실험
- 이 결과를 기준으로,
    
    이후 **일반화 실험(tv_ratio<1.0)** 에서 오차가 얼마나 증가하거나 감소하는지를 비교하면
    
    **모델의 실제 적용 가능성(일반화 성능)** 을 평가할 수 있음
