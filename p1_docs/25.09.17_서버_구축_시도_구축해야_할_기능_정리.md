## FastAPI 서버 구축

## FastAPI 선택 이유

### **1. OpenCV + 이미지 처리**

- FastAPI는 Python 기반 → OpenCV, NumPy, scikit-image, TensorFlow Lite 같은 이미지 처리·머신러닝 라이브러리와 바로 연동 가능
- NestJS는 Node.js 기반이라 OpenCV 사용 시 `opencv4nodejs` 같은 서드파티 바인딩에 의존해야 하고, 빌드/호환 문제가 자주 발생함
- 이번 프로젝트의 핵심은 **컬러카드 ROI 추출, 보정 행렬(CCM), Lab 변환** 같은 이미지 처리
    
    → **Python 생태계가 비교적 안정적일거라 생각함**
    

### **2. 확장성과 아키텍처 적합성**

- Flutter 앱과 IoT 기기(ESP32)에서 데이터를 받아야 함
    - **센서 Raw RGB**
    - **스마트폰 카메라 이미지 (얼굴, 컬러 카드)**
- FastAPI는 **멀티파트(FormData + 파일 업로드) 처리**가 간단하고, 바로 OpenCV로 넘겨서 처리 가능
- NestJS도 가능하지만, 파일 업로드 → Python 모듈 호출 → 다시 Node.js로 전달 같은 “이중 레이어” 구조가 필요할 수 있음
