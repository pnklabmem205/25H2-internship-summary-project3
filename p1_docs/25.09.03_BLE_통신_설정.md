- colorsensor(TCS34725 - xiao esp32c3 연동 후 색 인지) 폴더와 BLE(블루투스 통신) 폴더를 따로 생성했었음.

```jsx
colorsensor/   (PlatformIO 프로젝트 A)
 BLE/           (PlatformIO 프로젝트 B)
```

- BLE(`main.cpp`) 에서 esp32c3의 블루투스 연동 초기 코드

```cpp
#include <ArduinoBLE.h>  // BLE 라이브러리 불러오기

// BLE 사전 설정
#define SERVICE_NAME "arduinoBLE"
#define SERVICE_UUID "bd60209f-5bf2-4589-8e5b-c091bbbc6c19"
#define SERVICE_RXCHAR "e8b0cd3d-afaa-4a70-953d-591974c717a6"
#define SERVICE_TXCHAR "8fa584b0-0b84-4aad-b739-2f0b8aebb79e"
BLEService testservice(SERVICE_UUID);
BLEStringCharacteristic rxChar(SERVICE_RXCHAR, BLEWriteWithoutResponse | BLEWrite, 20);
BLEStringCharacteristic txChar(SERVICE_TXCHAR, BLENotify, 20);

// 초기 설정문 ( 전원 인가후 최초 1회 실행 )
void setup() {
  // BLE 설정
  BLE.begin();
  BLE.setLocalName(SERVICE_NAME);
  BLE.setAdvertisedService(testservice);
  testservice.addCharacteristic(rxChar);
  testservice.addCharacteristic(txChar);
  BLE.addService(testservice);
  BLE.advertise();

  Serial.begin(115200);
}

// 반복문 ( 초기 설정문 실행 후 반복 실행 )
void loop() {
  BLEDevice central = BLE.central();
  if (central) {
    // BLE 연결 시 최초 1회 실행될 명령입니다.
    Serial.println("connected");
    while (central.connected()) {
      // BleBegin 함수 실행후 연결 해제까지 반복 실행될 명령입니다.
      txChar.writeValue("hello");
    }
    // BLE 연결 해제시 최초 1회 실행될 명령입니다.
    Serial.println("disconnected");
  }
}
```

- “hello” 대신 컬러 센서로 읽어온 RGB 값의 표시를 위해 BLE 폴더 안에 colorsensor 폴더의 
센서 코드(`colorsensor.cpp`, `colorsensor.h` )를 넣음.

```jsx
BLE/
├─ src/
│   ├─ main.cpp         (BLE 코드)
│   ├─ colorsensor.cpp  (컬러센서 코드)
│   └─ colorsensor.h
└─ platformio.ini
```

- 컬러 센서로 읽은 값이 콘솔에 출력되고 블루투스 연결 한 기기에도 출력됨.
