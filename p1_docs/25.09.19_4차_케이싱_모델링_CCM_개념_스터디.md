## CCM(Color Correction Matrix)

---

## 1. CCM이란?

- 센서가 읽은 **RGB**를 사람 눈 기준 **표준 색공간(보통 CIE XYZ 또는 sRGB-linear)** 로 **선형 변환**해주는 3×3 행렬
    
    ![image.png](attachment:a4999372-9b5f-454e-889f-37e9942a0cb8:image.png)
    
    - R,G,B = 센서가 측정한 값(블랙/화이트 캘리 후)
    - X, Y, Z = CIE 표준(사람 눈 기준) 값
    - $aij$ = **우리 장비/조명/거리/각도**에 맞춰 실험으로 구하는 계수
    
    ### 왜 필요한가?
    
    - TCS34725의 **R/G/B 필터 대역**은 사람 눈의 R/G/B(혹은 sRGB/XYZ)와 **다르게 겹침**
        
        → 채널 간 **섞임** 발생
        
    - Gain/Integration/LED 세팅 조정만으로는 **근본적 색 왜곡**이 남음
    - **CCM은 채널을 서로 “섞어서/빼서”**(비대각 성분) 사람 눈 기준 색에 맞춰주는 역할
    - 즉, 센서 고유 RGB를 표준 색 좌표로 번역하는 변환 작업을 위함

## 2. TCS34xx 시리즈 애플리케이션 노트

[TCS34xx_AN000517_1-00.pdf](attachment:9c1608d0-038b-4ec1-a8fe-3bb685b34c68:TCS34xx_AN000517_1-00.pdf)

- 문서에서는 “CCM”이라는 표현 대신 **RGB→XYZ 변환 행렬** 또는 **Correlation Matrix**로 소개

### 흐름

**(A) 센서 RGB → XYZ**

**왜?:** 

- 센서의 필터(R/G/B)가 사람 눈의 R/G/B와 일치하지 않음
    
    → 그냥 쓰면 빨강/파랑/초록이 다 섞여서 “왜곡” 발생
    

**해결:**

- 3×3 변환 행렬(CCM)을 곱해서, 센서 RGB를 **CIE XYZ 색공간**으로 변환.

**XYZ가 뭐냐?:** 

- **X:** 빨강+초록 성분
- **Y:** 밝기(luminance), 초록 성분 중심
- **Z:** 파랑 성분
- 사람 눈이 인식하는 색을 수학적으로 표현할 수 있는 표준 좌표계

**(B) XYZ → xy 색좌표**

**왜?:** 

- 색을 좌표로 표현할 때, 밝기(Y)를 빼고 색깔 위치만 보고 싶을 때

**어떻게?:** 

$$
⁍
$$

**결과:**

- (x,y) = **색깔 좌표** (밝기 제외)
    
    → 색도도(Chromaticity diagram)에 점 찍을 때 이 좌표를 씀
    

**(C) xy → CCT(색온도)**

**왜?:** 

- 광원의 색을 Kelvin(K) 값으로 표현하기 위해
    
    (예: 전구 = 3000K, 햇빛 = 5500K)
    

**어떻게?:** 

- (x,y) 좌표를 공식(McCamy 등)에 넣으면 → **색온도(CCT)** 계산 가능

**즉, 이번 목표는 컬러카드 기준 값과 센서 값이 최대한 일치하는 것이기 때문에 (A) 단계의 센서 RGB → XYZ 변환(CCM) 을 내 환경(조명, 거리, 각도)에 맞춰 학습하는 것이 중요**

## 3. CCM 구하는 방법

1. **환경 고정**
2. **블랙/화이트 캘리브레이션**
3. **컬러카드 측정**: 센서 RAW RGB 수집
4. **기준 XYZ 데이터** 준비 (컬러카드 기준 값)
5. **최소자승법**으로 3×3 행렬(계수) 학습
    - 모든 패치에 대해 오차가 최소가 되는 행렬 M을 찾는 방법
6. 런타임에 [X,Y,Z] = M·[R,G,B] 적용
7.  XYZ → sRGB
