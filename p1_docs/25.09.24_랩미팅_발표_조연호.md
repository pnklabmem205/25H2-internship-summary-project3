# 🎤 컬러센서 기반 피부색 측정기 – 센서 정확도 개선 연구

👉 **성과 요약: 센서 컬러 인식 정확도를 패치 실험 + CCM 적용으로 약 40% 개선**

---

## 1. 프로젝표 목표

- 최종 목표: **컬러센서를 활용한 피부색 측정기 제작**
- 프로젝트 구성
    1. 센서로 RGB & 피부색 측정
    2. 앱에서  얼굴사진·컬러카드 촬영 → RGB 추출
- 현재 진행: 위 2가지 중 **① 센서 RGB 측정 파트 진행**

---

## 2. 프로젝트 배경

- **필요성**: 피부 진단, 개인 맞춤 서비스 등에서 **정확한 색 인식이 핵심**
- **문제의식**: 센서 기본 출력 값의 높은 오차율
- **연구 목표**: 센서 정확도 향상 (오차율 10%이내)

---

- **케이싱 (1차~4차)**
    1. **외부 빛 차단** → 주변 조명·햇빛 등 환경광이 들어오면 센서 값이 흔들림 → 케이싱으로 차단
    2. **LED 직광 차단 & 반사광만 수집** → LED 빛이 바로 들어가면 값이 왜곡됨 → 표면에서 반사된 빛만 들어오게 설계
    3. **센서–표면 거리 일정화** → 거리에 따라 값이 달라지므로 고정 거리 유지 필요
    4. **실험 재현성 확보** → 케이싱 구조를 통일하여 누가 어디서 측정해도 비슷한 조건 유지 가능

## 4. 실험: 10/20/24 패치 실험

- **목적**: 센서 raw RGB → 환경 보정(노출 등) & 데이터 처리(CCM 보정) → 컬러카드의 정확한 RGB 출력

### ✅ 핵심 결과

- **3×3 CCM 적용 후 적용 전보다 평균 오차율 약 40% 개선**
- **N=20** 훈련이 가장 안정적(낮은 MAE, 변동성↓)
- 단, **빨강 B 채널**에서 악화 케이스 존재(교차감응 영향)

---

### ⚙️ 실험 세팅

- **노출 고정**: ATIME **700ms**, GAIN **16×**
- **밝기 목표**: 흰 패치 **C≈10k–30k**, 블랙 **C<50**, 채널 RAW **<55k** (포화방지)

    - 컬러카드 30장 중 **10 / 20 / 24개**를 랜덤으로 훈련 용으로 뽑고

## 7. 향후 계획 / 개발 방향

### 1) **목표 범위 재정의**

- 전체 색상 일반화 대신 **피부톤 특화**로 전환
- 스킨 톤 버킷 정의: **밝/중/어두운 피부 × 웜/뉴트럴/쿨** (예: 3×3 = 9 버킷) → 미정

### 2) **데이터 전략 (대표 색 100개 설계)**

- **대표색 100개** 선정: 스킨 톤 중심 + 저채도 주변색(그레이, 흰/검, 보정용 중성) 포함
- 단계적 학습
    - **1차**: 20개 훈련 / 나머지 검증
    - **2차**: 20 + 40 (=60) 훈련 / 나머지 검증
    - **3차**: 20 + 40 + 20 (=80) 훈련 / 나머지 검증

### 3) **측정 프로토콜**

- **훈련/검증:** 색 당 10회 반복 → 평균
    - 기존에는 센서를 가만히 두고(고정된 상태) 반복 측정했다면
    - 이번에는 센서를 컬러카드의 여러 부분(해당 색상 내)을 반복 측정하여 평균

### 4) **하드웨어/광학 세팅**

**A. 현재 세팅**                 

- 케이싱(4차 버전) + WS2812 LED 단일 모듈 (4개)
- 노출: ATIME 700ms, GAIN 16×
- 이 조건에서 **훈련/검증 실험 진행**

**B. 세팅 개선**

- **LED 추가** 또는 밝기 증대 → 광량 확보
- ATIME × GAIN 매트릭스 실험 → 최적 노출 안정화
- 동일한 방식으로 **훈련/검증 반복** → 개선 효과 비교

### 5) **모델/보정 고도화 (스킨톤 중심)**

- 전체 색을 다 맞추는 대신 **피부톤 색상에 더 집중해서 보정**
