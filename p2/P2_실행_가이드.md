# IoT 섹션 (ESP32-S3-CAM)

## 1. 개발 환경 준비

### 1.1 필수 소프트웨어 설치

#### ESP-IDF v5.4.2 설치

1. **ESP-IDF 다운로드**
   - 공식 사이트: https://dl.espressif.com/dl/esp-idf/
   - 또는 GitHub: https://github.com/espressif/esp-idf.git
   - **버전: ESP-IDF v5.4.2** (반드시 이 버전 사용)

2. **Windows 설치 방법**
   ```powershell
   # Git이 설치되어 있어야 함
   git clone --recursive https://github.com/espressif/esp-idf.git
   cd esp-idf
   git checkout v5.4.2
   git submodule update --init --recursive
   
   # ESP-IDF 설치 스크립트 실행
   .\install.bat esp32s3
   
   # 환경 변수 설정 (PowerShell)
   .\export.ps1
   ```

3. **설치 경로 확인**
   - 기본 경로: `C:\esp\esp-idf` 또는 사용자 지정 경로
   - 설치 후 `idf.py --version` 명령으로 확인

#### ESP-WHO 다운로드

1. **ESP-WHO 클론**
   ```powershell
   cd C:\WS  # 또는 원하는 작업 폴더
   git clone https://github.com/espressif/esp-who.git
   cd esp-who
   ```

2. **버전 확인**
   - 사용 버전: `v0.9.4-258-g9f6d69d` (최신 main 브랜치)
   - 프로젝트는 `examples/human_face_recognition` 예제를 기반으로 커스터마이징

#### Python 3.10 이상 설치

- Python 3.10.8 이상 필요
- ESP-IDF 설치 시 자동으로 포함되지만, 별도 설치도 가능
- 참고: `Python_3.10.8_설치_가이드.md`

## 2. 하드웨어 구성

### 2.1 필수 하드웨어

| 항목 | 사양 | 비고 |
|------|------|------|
| **ESP32-S3-CAM** | OV2640 카메라 모듈 | ESP-WHO는 OV5640 미지원 |
| **USB-C 케이블** | 데이터 전송 가능 | 전원 공급 + 펌웨어 업로드 + 시리얼 출력 |
| **Wi-Fi 공유기** | 2.4GHz 지원 | ESP32는 5GHz 미지원 |

### 2.2 선택 하드웨어 (서보모터 PTZ 기능)

| 항목 | 사양 | 비고 |
|------|------|------|
| **서보모터 (PAN/TILT)** | SG90 2개 | 팬(좌우), 틸트(상하) |
| **외부 전원** | 5V 1A~2A | 서보모터 전원용 (USB만으로는 부족할 수 있음) |

**서보모터 연결:**
- PAN 서보: GPIO 13
- TILT 서보: GPIO 14
- 공통 GND 필수

### 2.3 하드웨어 연결 확인

1. **ESP32-S3-CAM 연결**
   - USB-C 케이블로 PC 연결
   - Windows에서 COM 포트 확인 (장치 관리자)

2. **서보모터 연결 (선택)**
   - 서보 신호선 → ESP32 GPIO
   - 서보 VCC → 5V (외부 전원 권장)
   - 서보 GND → ESP32 GND

## 4. 웹 UI 접속 및 사용

### 4.1 접속

1. **ESP32 IP 확인**
   - 시리얼 모니터에서 `Got IP: 192.168.0.15` 확인
   - 또는 공유기 관리 페이지에서 확인

2. **브라우저 접속**
   ```
   http://192.168.0.15/
   ```

### 4.2 얼굴 등록

1. **등록 탭 클릭**
2. **이름 입력** (예: "홍길동")
3. **등록 버튼 클릭**
   - ESP32가 현재 프레임에서 얼굴을 자동으로 캡처
   - 임베딩 생성 후 `/spiflash/faces.bin`에 저장
4. **등록 완료 확인**
   - 스트림 화면에서 얼굴 박스 위에 이름이 표시됨

**팁:**
- 한 사람당 여러 번 등록 가능 (최대 5개 샘플)
- 정면, 약간 왼쪽, 약간 오른쪽 각도로 등록하면 인식률 향상

### 4.3 얼굴 삭제

1. **리스트 탭 클릭**
2. **등록된 사용자 목록 확인**
3. **삭제 버튼 클릭**
   - ID로 삭제 또는 이름으로 삭제 가능

### 4.4 Threshold 조정

1. **설정 탭 (또는 메인 화면)**
2. **Threshold 슬라이더 조정**
   - 범위: 0.30 ~ 0.95
   - 낮을수록 엄격 (False Accept 감소)
   - 높을수록 관대 (False Reject 감소)
   - 권장: 0.60 ~ 0.75
3. **저장 버튼 클릭**
   - NVS에 영구 저장됨

### 4.5 출입 로그 확인

1. **출입 로그 탭 클릭**
2. **서버에서 최근 로그 자동 조회**
   - 서버가 실행 중이어야 함
   - 서버 IP가 올바르게 설정되어 있어야 함

## 6. 문제 해결

### 6.1 빌드 오류

**문제:** `idf.py build` 실패
- **해결:** ESP-IDF 버전 확인 (v5.4.2 필수)
- **해결:** `idf.py fullclean` 후 재빌드

### 6.2 플래싱 오류

**문제:** `Failed to connect to ESP32`
- **해결:** COM 포트 확인
- **해결:** USB 케이블이 데이터 전송 가능한지 확인
- **해결:** 보드의 BOOT 버튼을 누른 채로 플래싱 시작

### 6.3 Wi-Fi 연결 실패

**문제:** `Wi-Fi connection failed`
- **해결:** SSID/비밀번호 확인
- **해결:** 2.4GHz 네트워크인지 확인 (5GHz 미지원)
- **해결:** 공유기 MAC 필터링 확인

### 6.4 카메라 초기화 실패

**문제:** `Camera init failed`
- **해결:** OV2640 카메라 모듈 연결 확인
- **해결:** 보드 전원 공급 확인 (USB 전원 부족 가능)

### 6.5 얼굴 검출 안 됨

**문제:** 스트림은 나오지만 얼굴 박스가 안 보임
- **해결:** 조명 확인 (너무 어둡거나 역광 주의)
- **해결:** 얼굴과 카메라 거리 확인 (권장: 40~50cm)
- **해결:** Threshold 값 낮추기

### 6.6 서버 연결 실패

**문제:** 출입 로그가 서버에 저장 안 됨
- **해결:** 서버 IP 주소 확인
- **해결:** 서버가 실행 중인지 확인
- **해결:** 네트워크 방화벽 확인

## 6. 데이터베이스 관리

### 6.1 로그 조회 (SQL)

```sql
-- 최근 10개 로그 조회
SELECT * FROM access_logs 
ORDER BY event_time DESC 
LIMIT 10;

-- 특정 사용자 로그 조회
SELECT * FROM access_logs 
WHERE face_name = '홍길동' 
ORDER BY event_time DESC;

-- 날짜별 통계
SELECT 
    DATE(event_time AT TIME ZONE 'Asia/Seoul') as date,
    COUNT(*) as count
FROM access_logs
WHERE result = 'SUCCESS'
GROUP BY DATE(event_time AT TIME ZONE 'Asia/Seoul')
ORDER BY date DESC;
```

### 6.2 로그 삭제

```sql
-- 오래된 로그 삭제 (30일 이상)
DELETE FROM access_logs 
WHERE event_time < NOW() - INTERVAL '30 days';

-- 전체 삭제 (주의!)
-- DELETE FROM access_logs;
```

## 7. 문제 해결

### 7.1 서버 실행 오류

**문제:** `ModuleNotFoundError: No module named 'fastapi'`
- **해결:** 가상환경이 활성화되었는지 확인
- **해결:** `pip install fastapi` 재실행

**문제:** `Address already in use`
- **해결:** 포트 8000이 이미 사용 중
- **해결:** 다른 포트 사용: `--port 8001`

### 7.2 데이터베이스 연결 오류

**문제:** `could not connect to server`
- **해결:** PostgreSQL이 실행 중인지 확인
  ```powershell
  docker ps  # Docker 사용 시
  ```
- **해결:** `.env` 파일의 `DATABASE_URL` 확인
- **해결:** 방화벽 설정 확인

**문제:** `password authentication failed`
- **해결:** `.env`의 사용자명/비밀번호 확인
- **해결:** PostgreSQL 사용자 권한 확인

### 7.3 CORS 오류

**문제:** 브라우저에서 `CORS policy` 오류
- **해결:** FastAPI에 CORS 미들웨어가 설정되어 있는지 확인
- **해결:** `app/main.py`에 다음 코드 확인:
  ```python
  from fastapi.middleware.cors import CORSMiddleware
  
  app.add_middleware(
      CORSMiddleware,
      allow_origins=["*"],
      allow_credentials=True,
      allow_methods=["*"],
      allow_headers=["*"],
  )
  ```

### 7.4 ESP32에서 서버 연결 실패

**문제:** 출입 로그가 저장되지 않음
- **해결:** 서버 IP 주소 확인 (ESP32 설정 파일)
- **해결:** 서버가 실행 중인지 확인
- **해결:** 네트워크 연결 확인 (같은 Wi-Fi 네트워크)
- **해결:** 서버 로그 확인 (요청이 들어오는지)


**서비스 파일 내용:**
```ini
[Unit]
Description=Face Entry Server
After=network.target

[Service]
User=your-user
WorkingDirectory=/path/to/esp-who-face_entry_server
Environment="PATH=/path/to/venv/bin"
ExecStart=/path/to/venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
```
